Increase Maintenance Counters#

🔒 MaintenanceActivityOrder.IncreaseCounters

Overview#

This operation allows you to increase the maintenance counters of Maintenance Activity Orders (MAOs) associated with a Resource, a Container or an Area.

Note

The same counter may be used multiple times in the same Resource in different MAOs.

Preconditions#

  • The Resource, the Container or the Area exist, are Active, and have an associated Maintenance Plan Instance.
  • The user must belong to the Maintenance Plan Instance Owner Role.
  • At least one Event must be selected to ensure that at least one counter is incremented.

Sequence of Steps#

The Increase Maintenance Counters wizard can be called from the Resource, the Container or the Area page within the Business Data Group.

Step 1#

  1. Go to the Maintenance view of the Resource, Container, or Area.
  2. Select Increase Counters on the top ribbon to open the wizard.
  3. For each Event you can increase values for counters - Quantity One and Quantity Two.
  4. Verify other details.
  5. Optionally, enter a Comment.
  6. Select Increase to complete the operation.

Info

When the Increase Maintenance Counters operation is not executed manually and is triggered by an external event, different Counter Types apply to different entities:

  • Count One - applies exclusively to Resources
  • Count Quantity One - applies exclusively to Materials
  • Count Quantity Two - applies exclusively to Materials

For more information, see Update Maintenance Activity Order Schedule/Counters.
