Maintenance Activity Order Page#

🔒 MaintenanceActivityOrder.Show

Details#

The Maintenance Activity Order (MAO) page displays all the operations that can be performed within a specific MAO. Additionally, it displays the Details of the MAO, as illustrated below:

Data Collection#

By selecting the Data Collection section, on the right of the screen, all the Data Collection Parameters are displayed, alongside their Sample IDs and Readings, in read-only mode:

Checklist#

The Checklist section displays the existing checklist(s), associated with the current MAO and all the Checklist items:

Parts#

The Parts section displays a list of the parts that are necessary to execute a BOM and, consequently, a MAO, and that are associated to a specific Product. For each Part, information on quantities and cost are also displayed.

Labor#

The Labor section displays the name of the Employee(s) associated with the current MAO and all the related Employee-specific information, such as Certifications, Checked-In Date, Begin and End Dates, Duration, Cost, and Exclusiveness.

Personnel#

The Personnel section displays a summary of the previously defined Check-in Options and of the Labor Hours.

Transfer Requirements#

All Transfer Requirements associated to the MAO are listed in this section.

Qualifications#

The Qualifications section displays a summary of the Qualification Checks and the Qualification Items associated with the current MAO. This section is only displayed if the Maintenance Plan scope is set to Qualification. For more information, see Create Maintenance Plan.

Documents#

The Documents associated to this MAO are available in this section.

Past MAOS / Joined MAOS#

When selected, these sections display, respectively, a list of past MAOs or active MAOs that were joined with a Parent MAO. From this list you can obtain information on the execution or the schedule states of the MAOs, along with their begin and end dates.
