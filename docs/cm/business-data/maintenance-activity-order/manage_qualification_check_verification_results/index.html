Manage Qualification Check Verification Results#

🔒 MaintenanceActivityOrder.SetQualificationVerificationResults

Overview#

This operation manages Qualification Check Verification Results when the Verification Mode is set to Manual. To set Verification Results when the Verification Mode is not Manual, use the Special Manage Qualification Check Verification Results operation.

Tip

Verification Results can be captured in any order.

The following actions are supported:

  • Clear a previously failed or passed result;
  • Set a result to Pass;
  • Set a result to Fail.

Preconditions#

  • The MAO exists and is Active.
  • The MAO Maintenance Type is set to Qualification.
  • The MAO Material Type Restriction Mode is set to Require Specific.
  • The MAO Execution State is Requested, Approved, Released, In Progress, or Waiting For Acceptance.
  • The MAO Qualification Check is In Progress or In Verification, and the Verification Count is higher than 0.
  • There must be a Material assigned to the MAO Qualification Check Verification.
  • The Verification Mode of the MAO Qualification Check Verification must be set to Manual.

Sequence of Steps#

Record Result#

  1. Select a Maintenance Activity Order that matches the preconditions listed above.

  2. Navigate to the Qualifications section of the MAO.

  3. Select the number in the last column, which opens the view with all the Verifications configured for the selected Qualification Check.

  4. Choose one or more Verifications matching the preconditions, select Record Result and for each Verification:

    • Choose a Material belonging to the MAO;
    • Select the Result by choosing Pass or Fail;
    • Optionally, enter a remark.

  5. Select Record to complete the operation.

Clear Result#

A result can only be changed by first using the Clear Result operation. A Result can be cleared when it is set to Fail or Pass. Moreover, when the MAO Material Type Restriction Mode is set to Require Specific, a Qualification Check can never permanently fail. In this case, the check must be repeated until the Result is set to Pass. To Clear a Result:

  1. Choose one or more Verifications with Result set to Fail or Pass and select the Clear Result button.

  2. Select Clear to complete the operation.
