Special Update Maintenance Activity Order Schedule/Counters#

🔒 MaintenanceActivityOrder.SpecialUpdateScheduleAndCounters

Overview#

This operation updates the schedule and counters of a Maintenance Activity Order (MAO). This transaction is similar to the Update Maintenance Activity Order Schedule and Counters except that the current user is not required to belong to the Maintenance Plan Instance Owner Role of the MAO.

Preconditions#

  • The MAO is in the execution state Requested, Approved, or Released.
  • The MAO is not Ad hoc.
  • If the MAO is included in another MAO, that is, the Parent MAO property is not null, this operation can only be performed if the Schedule Type of the MAO is set to Usage Based or Time And Usage Based. In this case, the only property that can be modified is the Usage Counter value.

Sequence of Steps#

Step 1#

  1. Verify the information regarding the MAOs.

    Note

    It is possible to select multiple MAOs before entering the Special Rework Maintenance Activity Order wizard.

  2. For Time Based and Time And Usage Based MAOs, set the Time Early Due, Time Due and Time Late Due.

    Note

    Ensure that Time Early Due is set to a value earlier than Time Due, and Time Due is earlier than Time Late Due.

  3. For Usage Based and Time And Usage Based MAOs, set the Usage Early Due, Usage Due and Usage Late Due.

    Note

    Ensure that Usage Early Due is set to a value lower than Usage Due, and Usage Due is lower than Usage Late Due.

  4. For Time Based and Time And Usage Based MAOs, it is possible to set the Schedule Date.

  5. Optionally, enter a Comment.
  6. Select Update to complete the operation.
