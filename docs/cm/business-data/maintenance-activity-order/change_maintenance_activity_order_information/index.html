Change Maintenance Activity Order Information#

🔒 MaintenanceActivityOrder.Change

Overview#

This operation is used to change the information contained in a Maintenance Activity Order (MAO) object.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The MAO exists in the system, is Active, and the execution state is Requested, Approved, Released, In Progress, or Waiting For Acceptance.
  • The user must belong to Owner Role of the Maintenance Plan Instance to which the MAO belongs.
  • The Maintenance Type of the MAO must not be set to Qualification.

Sequence of Steps#

The Change Maintenance Activity Order Information wizard can be called from the MAO page within the Business Data Group. Upon opening the MAO, you can edit:

  • The Description.
  • If it is a specific Employee or an Employee belonging to a specific Role that executes the MAO. Depending on what is selected, you can also edit the Employee or the Role to execute the MAO.
  • The Scheduled Date. This option is not available if the Maintenance Activity Schedule Type is set to Ad hoc.
  • The Expected Duration.
  • The Notes.
  • Optionally, you can enter a Comment.

When the changes are finished, select the Change button to save the new values and return to the MAO.
