Edit Qualification#

🔒 Qualification.Edit

Overview#

This operation is used to edit a Qualification.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Qualification exists in the system.

Sequence of Steps#

The Edit Qualification wizard can be called from the Qualification page within the Business Data Group.

Step 1: General Data#

All non-system properties can be changed in this wizard.

The Name of the Qualification cannot be altered.

  1. Optionally, edit the description.
  2. Change the Type by selecting a value from the Qualification Type Lookup Table.
  3. Optionally, assign or modify the associated Data Group.
  4. Update the Owner Role associated to the Qualification. The list of Roles is retrieved from the Roles currently configured in the system.
  5. Optionally, select or change the Default Reason (values are taken from the Qualification Reason Lookup Table).
  6. Update the Information URL.
  7. Modify the assignment permissions:
    • Enable Allow Self-Assignment to allow an Employee to self-grant this Qualification.
    • Enable Allow Assignment By Manager to allow a Manager to grant or revoke this Qualification to/from a subordinate.
  8. Update the validity period.
  9. Specify whether the validity can be overriden by enabling Allow Override.
  10. Choose a Grace Period by defining a duration and a scale.
