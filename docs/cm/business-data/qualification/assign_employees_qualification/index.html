Assign Employee(s) To Qualification#

🔒 Qualification.AssignEmployees

Overview#

This operation is used to assign a Qualification to one or more Employees, meaning that the Employee possesses the Qualification at a certain proficiency level.

Note

Organization proficiency levels are defined in the Generic Table QualificationProficiency.

Info

The Rank of the Proficiency is defined in numbers, and you can define the highest value as being the lowest rank or vice-versa depending on you location and culture.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Qualification to be assigned must exist and be Active.
  • The selected input list of Employee(s) must match any of the following conditions:
    • User is member of the Owner Role.
    • Employee is Manager of the Employee in the Employee Qualification and the Qualification has the property IsManagerAssignAllowed set to true.
    • Current user is the same Employee in the Qualification
    • The Qualification has the property IsSelfAssignAllowed set to true.

Sequence of Steps#

Step 1: Employees#

  1. Select the Employee(s) to be assigned to the Qualification from the left grid. Employee(s) can be filtered by Team, Manager or by a simple name filter. Selecting the Employee will add them to the list of selected Employee(s) on the right side of the screen.
  2. Select Next to define the Qualification details.

Step 2: Qualification#

  1. It is necessary to define the proficiency and the reason for the Qualification. The default reason will be taken automatically if it is defined.
  2. If there is a validity defined, it will be set automatically. If the Qualification allows the validity to be overridden, the user may override it.
  3. Optionally enter a remark for the assignment.
  4. Optionally enter the evidence for the Qualification achievement.
  5. Select Assign to complete the operation.

Warning

If a Validity Period is defined, it must be greater than the Qualification Date.
