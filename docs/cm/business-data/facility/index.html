Facility#

🔒 Facility.Show

Overview#

A Facility corresponds to a physical shop floor location, which can be local or remote.

The following objects are assigned specifically to a Facility:

  • Materials
  • Containers
  • Resources

Materials can only be transferred between Facilities via a Ship Material transaction.

Sequence Of Steps#

The necessary steps for correctly creating and using a Facility are:

  1. Optionally, create a Calendar to be used as default.
  2. If the Facility is remote, a Site must be created first.
  3. Create the Facility, optionally assign a default Calendar.

Info

The default Calendar will be used for all the Areas created for that Facility.
