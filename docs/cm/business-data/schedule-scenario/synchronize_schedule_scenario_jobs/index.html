Synchronize Schedule Scenario Jobs#

🔒 ScheduleScenario.Synchronize

Overview#

This operation calculates/gathers all the necessary information from the Factory Model (Resources, Steps, Materials, etc.) to generate the Schedule Scenario. In practice, when Synchronizing, the system takes a snapshot of the current status of the Factory; as such, whenever changes (which are significant to Scheduling) have occurred, it would be necessary to Synchronize, so as to take these changes into consideration.

Note

When a Schedule Scenario is created, the Synchronizing operation is automatically triggered.

Info

To know which information is taken into consideration, see Scheduling Setup and Scheduling Functionalities.

Preconditions#

  • Schedule Scenario must be NonSynchronized, Synchronized or Processed.

Sequence Of Steps#

  1. Choose an appropriate Schedule Scenario and select the Sync Jobs button on the top ribbon.
  2. Review the Schedule Scenario details.
  3. Select Synchronize to perform the operation.

Info

A progress window will be displayed after finishing the wizard, and will disappear automatically when the synchronization is complete.

Note

Since the synchronization consists in taking a snapshot of the Factory Model, this operation may take some time.
