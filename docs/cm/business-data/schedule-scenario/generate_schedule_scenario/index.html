Generate Schedule Scenario#

🔒 ScheduleScenario.Generate

Overview#

This operation generates a valid Schedule Scenario, attempting to sequence all the required Schedule Scenario Jobs (that is, all the Steps that each Material has to go through). The Generation

Info

The Generation operation takes into account the information from the last Synchronization.

Preconditions#

Schedule Scenario must be in the state Synchronized or Processed.

Sequence Of Steps#

  1. Press Generate.

Step 1: General Data#

  1. Review the Schedule Scenario information.

Step 2: Untie Sort Rules#

  1. Optionally, override the default Untie Sort Rules defined at the Schedule level.

  2. Add as many Untie Sort Rules as desired.

  3. For each added Untie Sort Rule, specify the Rule and the direction.

Info

At least one Untie Sort Rule must be added in order to proceed.

Step 3: Optimization Criteria#

  1. Optionally, override the default Optimization Criteria defined at the Schedule level.

  2. For each desired Criteria/Objective, give the desired weight either by dragging the slider, or by typing the value in the corresponding text box.

Info

The sum of all the weights must equal 100%

Info

In order to preserve the integrity of the results, it is recommend not to exceed 3 different criteria for a Generation.

  • Press Generate to complete the transaction.

Info

A Progress Window will appear after finishing the Wizard, disappearing automatically when the Generation is complete.

Info

Any possible Errors/Warning during the Generation will be stored in the Messages section of the Details View of the Schedule Scenario

Info

Note that since the Generation operation consists in sequencing all the Schedule Scenario Jobs (in other words, all the Steps that each Material has to go through), this operation may have a significant duration.
