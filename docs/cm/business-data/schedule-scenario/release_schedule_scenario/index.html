Release Schedule Scenario#

🔒 ScheduleScenario.Release

Overview#

This operation allows a Schedule Scenario to become the released scenario for the Schedule, setting the order of manufacturing execution (Track-In, Track-Out, Move-Next) for a given production schedule. After the release of a Schedule Scenario, it is no longer possible to synchronize the jobs, only adjusting is permitted.

Info

For more information on the workflow for the Planning/Replanning process, see Replanning.

Preconditions#

  • Schedule Scenario must be Processed.

Sequence Of Steps#

  1. Choose an appropriate Schedule Scenario and select the Release button on the top ribbon.
  2. Review the Schedule Scenario details.
  3. Select Release to perform the operation.

Info

The Release Operation is not possible for a Schedule Scenario of Generation Type PlanningSchedule. For more information, see Scheduling Modes.
