Manage Resource Trainees#

🔒 Resource.ManageTrainees

Overview#

This operation is used to manage the Employees set as Trainees for a specific Resource, allowing a Trainer to quickly check-in or check-out multiple Employees at a Resource for which the current user is set as Trainer.

Setup#

No setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • Resource is of Processing Type Process and has both Enable Check-In and Restrict Check-In set to true.
  • For a successful Check-In operation, all selected Employees are Active and set as trainee (Is Trainee is true in at least one valid Certification, which must be in state Active or Grace Period).
  • Current Employee is a Trainer in at least one valid Certification (must be in state Active or Grace Period).

Sequence of Steps#

You can access the Manage Resource Trainees wizard through the Area View or directly through a Resource. Using the Area View provides the extra advantage to check-in or check-out multiple Employees at multiple Resources.

Step 1: Resources (from Area View)#

  1. Select a Resource and then select Manage Resource Trainees from the dropdown button on the top ribbon.
  2. A dialog will open, listing all the selected Resources on the left side. Select the ones you want to manage and select Next.

Step 2: Trainees#

  1. A list of all available Trainees will be displayed on the right-hand side. Select the Trainees that should be checked-in to the Resource or unselect the Trainees that should be checked-out from the Resource.
  2. Select Update and the system will confirm that the Employees are checked-in to or checked-out from the Resource.
