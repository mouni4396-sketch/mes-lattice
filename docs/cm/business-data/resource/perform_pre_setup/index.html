Perform Pre Setup#

🔒 Resource.PerformPreSetup

Overview#

This operation is used to perform setup for a Material, on a given Resource, at a different Step from the current Step of the Material.

For more information, see Perform Setup and Perform Line Setup.

Setup#

No special set up is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource exists, it is Active and the Processing Type is Process or Line.
  • The Resource Setup Mode is different from Not Required.
  • The Resource Setup Begin and Complete Mode is either Auto Begin and Complete or Manual Begin and Complete.
  • If the Resource Setup Begin and Complete Mode is Manual Begin and Complete, the In Setup must be true, and the Current Setup Type will be Changeover Pre or No Changeover Pre.

Sequence Of Steps#

Step 1: General Data#

Auto Begin and Complete#

  1. Select a Resource matching the preconditions with the Setup Begin and Complete Mode set to Auto Begin and Complete.

  2. In the Perform button on the top ribbon, select the Perform Pre Setup option to open the wizard:

  3. In the first step of the Perform Pre Setup wizard, select a Material, and a future Step, and select Next:

  4. In the second step of the Perform Pre Setup wizard, define the Begin Setup for All Sub-Resources property - defaults to true:

  5. Optionally, enter a comment.

  6. Select Perform to complete the operation.

Manual Begin and Complete#

  1. Select a Resource matching the preconditions with the Setup Begin and Complete Mode set to Manual Begin and Complete.

    Info

    If the Setup Begin and Complete Mode is defined as Manual Begin And Complete, you will need to Begin Pre Setup before you can execute the Perform Pre Setup operation.

  2. In the Begin button on the top ribbon, select the Begin Pre Setup option to open the wizard:

  3. In the first step of the Begin Pre Setup wizard, select a Material, and a future Step, and select Next:

  4. In the second step of the Begin Pre Setup wizard, confirm the Setup Information and define the Begin Setup for All Sub-Resources property - defaults to true:

    Note

    For more information, see Begin Pre Setup.

  5. Select Begin to continue the operation and return to the Details page of the Resource.

  6. In the Perform button on the top ribbon, select the Perform Pre Setup option to open the wizard:

  7. Proceed as you would for Auto Begin and Complete (see above).

  8. Optionally, enter a comment.
  9. Select Perform to complete the operation.
