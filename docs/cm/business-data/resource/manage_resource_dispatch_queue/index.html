Manage Dispatch Queue#

🔒 Resource.ManageDispatchQueue

Overview#

This operation is used to manage the Resource's queue, i.e, the Material processing order.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource is Active in the system.

Sequence of Steps#

Step 1#

  1. When the wizard is open, select the directional arrows on the top right-hand side of the grid's toolbar to choose the position of the Material. Alternatively, it is possible to drag a Material and drop it in the desired order.
  2. If you want to revert the order of the Material, select the Reset button to reset the sorting.

  3. If the Resource has Lanes (Lane Count > 0), you must select which Lane you want to manage the order of (order will be per Lane in that case).

  4. Verify the Material information that is displayed on the right-hand side of the screen.

  5. Optionally, enter a Comment.

  6. Select Update to complete the operation.
