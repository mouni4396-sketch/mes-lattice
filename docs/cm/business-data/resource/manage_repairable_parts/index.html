Manage Repairable Parts#

🔒 Resource.ManagePartMaterials

Overview#

This operation allows you to manage all Resource Part Materials associated with a specific Resource. Before managing Part Materials, you must first define the Resource Parts. Only then will you be able to associate or update the Materials linked to each Part.

Setup#

No setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource exists and is Active.
  • The Resource has the Defines Resource Parts property enabled.
  • The Material is not yet associated with another Resource as a Resource Part.
  • The Material must be in the same Facility and its Primary Quantity must be 1.
  • If the Parts are Inserted or Replaced, the Product of the Resource Part must have the Part Type set to Repairable and the Part Quantity must be 1.

Sequence of Steps#

Step 1#

  1. Select an appropriate Resource, navigate to the Parts section, select the Manage button and then choose Repairable Parts from the dropdown list.

    Info

    The Repairable Parts option will only appear in the dropdown list after Resource Parts have been defined for the selected Resource. For more information, see Manage Resource Parts.

  2. In this wizard, you can insert, replace, or remove Materials associated with each Part.

    • To insert a Material, select one from the available list.
    • To remove a Material, select the icon.
    • To replace a Material, first remove the existing one, then select a new Material.

    Info

    The system automatically updates the status of each Part Material to reflect the action taken (Inserted, Replaced, or Removed). On the Resource page, the Parts section also displays the most recent insertion and removal dates.

  3. Optionally, enter a Comment.

  4. Select Update to complete the operation.
