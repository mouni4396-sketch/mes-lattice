Complete Line Setup#

🔒 Resource.CompleteLineSetup

Overview#

This operation is used to Complete an ongoing setup in the Sub-Resource(s) of a Line Resource.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The main Resource is of processing type Line.
  • The Sub-Resource property In Setup must be true.
  • If the Sub-Resource Setup Mode is different from Not Required:
    • All Documents that must have been Read and Understood were Read and Understood.
    • The Resource Current Setup Checklist Instance must be Completed.
    • All the Durables and Consumables must be set in the right positions and quantities.
    • The Recipe, if set manually, must match with the required Setup Recipe.
  • The Sub-Resource property Setup Begin and Complete Mode must be Manual Begin and Complete.
  • If there are Material Line Step Resources that match the setup Material, Resource, and Step, their Setup State must be In Progress.

Sequence of Steps#

Step 1: General Data#

  1. Select a Resource matching the preconditions.

  2. Select the Complete Line Setup button on the top ribbon to open the wizard:

  3. In the Complete Line Setup (Sub-Resources) wizard select the Resource(s) you want:

  4. The system will suggest a default transition, and if applicable, also a Reason, which you will be able to override.

  5. Optionally, enter a comment.
  6. Select Complete to complete the operation.

Info

You can also access the Complete Line Setup button through the Resource View.
