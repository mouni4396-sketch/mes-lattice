Perform Line Setup#

🔒 Resource.PerformLineSetup

Overview#

This operation is used to mark the Sub-Resource(s) of a Line Resource, indicating that the user is performing setup for a Material on a given Resource.

For more information, see Perform Setup and Perform Pre Setup.

Setup#

No special set up is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource exists, it is Active and the Processing Type is Line.
  • The selected Material must exist, must be Top-Most, must be Active, and the System State must be Queued or Dispatched.
  • The Resource and Sub-Resource(s) Setup Mode is different from Not Required.
  • The Resource must have at least one Sub-Resource of which the Processing Type must be Process.

Sequence Of Steps#

Step 1: General Data#

Sub-Resource: Auto Begin and Complete#

  1. Select a Resource matching the preconditions with the Setup Begin and Complete Mode for the available Sub-Resource set to Auto Begin and Complete.
  2. Go to the Resource View and select a Material.

  3. In the Perform button on the top ribbon, select the Perform Line Setup option to open the wizard:

  4. The Perform Line Setup (Sub-Resources) wizard will display the Sub-Resource(s) that are available to perform the line setup for the given Material:

    Note

    The available Sub-Resource(s) will be the one(s) with the Setup Begin and Complete Mode set to Auto Begin and Complete.

  5. Select one or more Sub-Resource(s) to perform the setup.

  6. Optionally, enter a comment.
  7. Select Perform to complete the operation.

Sub-Resource: Manual Begin and Complete#

Note

If the Setup Begin and Complete Mode for the Sub-Resource(s) is set to Manual Begin and Complete, you will need to Begin Line Setup in the main Resource.

  1. Select a Resource matching the preconditions with the Setup Begin and Complete Mode for the available Sub-Resource set to Manual Begin and Complete.

  2. In the Begin button on the top ribbon, select the Begin Line Setup option to open the wizard:

  3. In the Begin Line Setup (Sub-Resources) wizard, select the Sub-Resource that has the Setup Begin and Complete Mode set to Manual Begin and Complete, and select Begin:

  4. Back in the Resource View, select a Material, and select Perform Line Setup in the main Line Resource:

  5. The Perform Line Setup (Sub-Resources) wizard now displays both Sub-Resources:

  6. Select one or more Sub-Resource(s) to perform the setup.

  7. Optionally, enter a comment.
  8. Select Perform to complete the operation.
