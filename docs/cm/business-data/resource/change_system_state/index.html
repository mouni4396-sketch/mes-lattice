Change System State#

🔒 Resource.ChangeSystemState

Overview#

This operation is used to modify the Resource system state.

Setup#

No special setup is required to perform this operation.

Preconditions#

There are no preconditions for performing this operation.

Sequence of Steps#

  1. Press the Change System State button.
  2. Select the new system state - Down, Non-Scheduled or Up.
  3. Click Change to complete the transaction.

Info

The supplied SEMI E10 model contains attribute information that automatically updates the System State with the correct system state whenever a Change Resource State occurs. Essentially, it uses the information stored in the Basic attribute of each state.

Info

The standard Set or Unset Resource Dispatchable DEE Rule relies on information from the Resource System State.
