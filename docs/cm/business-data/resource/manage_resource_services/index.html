Manage Resource Services#

🔒 Resource.Edit

Overview#

This operation is used to manage the Services of the Resource.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource exists and it is Active.
  • The Service exists and it is Active.
  • The Processing Type of the Resource must not be Durable or Component.

Sequence of Steps#

Select an appropriate Resource, and navigate to the Services section. The Manage Resource Services wizard can be opened by selecting the Manage button.

Step 1: Manage Services#

  1. Add or remove Services as needed (select to add, and to remove).
  2. Define the priority of the Service for this Resource. This property can be helpful when selecting a specific Resource for a specific Service within a pool of Resources that provide the same Service.
  3. Specify whether the Service requires a running mode (defaults to false).
  4. Specify whether the Service is enabled at the Resource (defaults to true).
  5. Optionally, select a Qualification Check to be applied to the Service. This option is available only for Resources with Processing Type Process or Line.
  6. Select Next to continue.

Step 2: Required Sub-Service (optional)#

  1. Optionally, provide a list of the required Sub-Services for that service. You can add or remove services (select to add, and to remove) of which the Processing Type must be Process.
  2. Select Update to complete the operation.
