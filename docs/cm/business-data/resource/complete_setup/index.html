Complete Setup#

🔒 Resource.CompleteSetup

Overview#

This operation is used to mark the Resource as not being in Setup anymore.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Processing Type of the Resource is Process or Line.
  • The Resource property In Setup must be true.
  • If the Resource Setup Mode is different from Not Required:
    • All Documents that must have been Read and Understood were Read and Understood.
    • The Resource Current Setup Checklist Instance must be Completed.
    • All the Durables and Consumables must be set in the right positions and quantities.
    • The Recipe, if set manually, must match with the required Setup Recipe.

Sequence of Steps#

You can perform this operation from several points of entry:

  • From the Material - from the Material details page, select the Complete Setup button on the top ribbon to open the wizard.
  • If available, from the Production Order Step - from the Resource details page, go to the Schedule View, select the Production Order Step and select the Complete Setup button on the top ribbon to open the wizard.
  • From the Resource - the Resource is already selected, select the Complete Setup button on the top ribbon to open the wizard.

Step 1: Setup Mode Not Required#

  1. Select a Resource matching the preconditions.

  2. If the Setup Mode of the Resource is Not Required, select the Complete Setup button on the top ribbon to open the wizard:

  3. As the state of the Resource is subject to being changed, select a new state from the drop-down list. In case that the state transition is associated with Reasons, you can accept the suggested Reason or select another one:

  4. The system will suggest a default transition, and if applicable, also a Reason, which you will be able to override.

  5. Optionally, enter a comment.
  6. Select Begin to complete the operation.

Step 1: Setup Mode Is Required#

  1. If the Setup Mode of the Resource is Always or On Changeover, select the Complete Setup button on the top ribbon to open the wizard:

  2. The system will suggest a default transition, and if applicable, also a Reason, which you will be able to override.

  3. Optionally, enter a comment.

  4. Select Complete to complete the operation.

    Info

    If Running Mode and Lane configurations have been set, this information will also be available.

Note

If the Resource is a Top-Most Resource and its Processing Type is Line, you have the option to also Complete Setup for All Sub-Resources.

The default is taken from the GUIElementDefaultValue Generic Table with the following information: Context = Resource.CompleteSetup, Element = BeginSetupForAllSubResources, and Value = True (by default).
