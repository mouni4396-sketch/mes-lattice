Manage Consumable Feeds#

🔒 Resource.ManageConsumableFeeds

Overview#

This operation allows you to attach and detach Consumable Feed Resources to a parent Resource.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Resource is Active.
  • The Consumable Feed is Active and is not on Hold due to maintenance.
  • The Resource and Consumable Feeds are in the same Facility (via Area).
  • The Resource Number of Consumable Feed Positions is greater than 0 or the Has Resource Locations property of the Resource is set to true.

Sequence Of Steps#

  1. Select a Resource and then from the Manage button on the top ribbon, select Consumable Feeds.

  2. A Resource can have either Locations or Number of Consumable Feed Positions, not both. If the Has Resource Locations flag is active, expand the desired Consumable Feed Locations for which the attach or detach consumables operation is intended and select which feed will be placed where. Each location can have a specific number of Positions, defined in the Position Count property of the Location associated to the Resource.

  3. If the Has Resource Locations flag is not active, expand the desired Consumable Feed Positions for which the attach or detach consumables operation is intended and select which feed will be placed where.

  4. Optionally, enter a comment.

  5. Select Update to complete the operation.

Note

You can only attach a Consumable Feed to a Resource Location if the selected Consumable Feed Type is the same for both.
