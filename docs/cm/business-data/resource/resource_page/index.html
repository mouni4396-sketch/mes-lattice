Resource Page#

🔒 Resource.Show

The Resource page displays all the operations that can be performed within a specific Resource. Additionally, it displays the details of the Resource in different view modes, as described below.

GenAI

The Generative AI feature is available on this page. For more information, see GenAI.

Details View#

The Details view displays all the following information:

  • Details - displays general information on the Resource.
  • Structure - displays the Resource defined structure of Parent Resources and Sub-Resources and allows you to manage this structure.
  • Running Modes - displays the Resource defined running modes of Parent Resources and Sub-Resources and allows you to manage the running modes. Should only be visible if the Resource is of Processing Type Process.
  • Parts - displays a list of all Resource Parts defined for the Resource and allows you to manage the Parts and the Repairable Parts associated with the Resource.
  • Recipes - displays a list of all Recipes associated with the Resource. This section allows you to manage and upload Recipes to the Resource.
  • Run at Risk Materials - displays a list of all Materials that can be processed when the Resource is down for a Qualification Check. This section allows you to manage the Materials associated with the Resource.
  • Materials - shows which Materials are at the Resource. If Storage Bins are configured for the Resource, the Materials stored within the Storage Bins are displayed in this tab. If the Resource has Lanes configured, you will be able to filter by Lane and include this column in your data grid.
  • Instruments - allows the visualization and management of Resource instruments that are associated with the Resource.
  • Measurement Capabilities - displays information on the measurement capabilities of a Resource. Should only be visible if the Resource is of Processing Type Instrument.
  • Consumable Feeds - shows which Consumable Feeds are configured for the Resource. Should only be visible if the Resource is not of Processing Type Storage.
  • Locations - shows the Resource Locations currently configured for the Resource.
  • Lanes - shows the Resource Lanes currently configured for the Resource and other information that is set for the Lane, such as the Current Recipe.
  • Durables - shows which Durables are associated with the Resource.
  • Inventory - shows information on the Resource inventory. Should only be visible if the property Enable Automatic Replenishment is set to True.
  • Storage Bins - shows and allows management of the Storage Bins configured for the Resource. Should only be visible if the property Has Storage Bins is set to True.
  • Services - allows the visualization and management of Services that are associated with the Resource.
  • Personnel - displays information on the Employees, namely on Check-In and Check-Out information and on the Employees' Certifications.
  • Costing - enables the visualization of Resource Standard Costs previously entered by you (only if the Costing module is properly licensed in the system).
  • Protocols - shows any existing Protocols that were previously created for the Resource.
  • Resource Jobs - shows any existing Resource Jobs associated with the Resource.
  • Notifications - shows any existing Notification created for the Resource (only if the notifications optional module is properly licensed in the system).
  • Scheduling/Batching - displays information on the Scheduling and Planning of the Resource and allows you to manage them (only if the Scheduling module is properly licensed in the system).
  • Collected Data - enables the visualization of existing Data Collection.
  • Workgroups - displays information on the Shift Plans and teams/workgroups that are associated with the Resource.
  • Stored Materials - shows which Materials are stored in the Resource.
  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information on Attributes, visit the section Attributes.

  • Attachments - shows the documents that are attached to the Resource and enables you to attach additional documentation to the Resource.

Resource View#

Resource View for Processing Resources#

Warning

This is shown as Dispatch View when the Dispatch Schedule Type is set to Scheduling and Resource View when the property is set to Dispatching.

The Resource View shows an overview of the available Materials for processing at the selected Resource in the Dispatch List tab which includes only Materials in state Queued. In the Materials at Resource tab, the system displays all the Materials which are currently associated with the Resource. The total number of Materials in each of these states is shown alongside the Resource Name and State.

Note

To access the Resource View the feature Manufacturing.fabExplorer is required.

Each Material from the list will then show the properties that have been previously defined, as seen in the example below. The selection of one or more Materials, by ticking the respective checkboxes, will enable some of the buttons in the action bar, allowing you to perform the desired Resource operations.

Alongside the list of Materials, a column icon will be displayed. When selected, this icon will allow you to define the columns to be displayed for each material, as well as the type of sorting and filters. For more information on the layout configuration, see FabExplorer.

Info

The Materials on the list will sometimes be accompanied by badges to illustrate different underlying Material circumstances; for example, if a Material is InProcess and a Checklist for Track-Out has been previously associated to the Material, a badge will be displayed next to the Material, in order to indicate that the Material has a Checklist (long running) that needs to be completed before the Track-Out operation takes place.

When a Material is waiting for an Experiment in the Resource, a lock badge will appear in the column next to Material. Selecting it will display a pop-over message, as shown in the image below.

Resource View for Batch Resources#

For Batch Resources, the Resource View adapts to provide an overview of the available Batch Materials at a specific Resource, organized into four tabs:

  • Dispatch List - shows the available Materials for dispatching at the selected Resource. These Materials will be in the Queued state. When selecting one or more Materials, by ticking the respective checkboxes, some of the buttons in the action bar will be enabled, allowing you to perform different operations.
  • Planned Batches - shows the Batches available for release at the selected Resource. It also shows the Batch Materials that are associated with a given Batch. These Batches will be in the Created state. When selecting one or more Batches, some of the buttons in the action bar will be enabled, allowing you to perform different operations.
  • Batch at Resource - shows a list of the Batches In Process state. Among other operations, you may Track-Out or Abort a given Batch.
  • Processed Materials - shows a list of the Processed Batches; when selecting one or more Batches, you may perform different operations.

Schedule View#

The Schedule View is available when the Dispatch Schedule Type is set to Scheduling. This view provides a timeline view of the Materials or Production Order Steps planned for this Resource. You can choose one of the possible different views for the listed Production Order Steps:

  • Planned Jobs / Materials - depending on the value of the Schedule View Mode property:

    • Material - displays a comprehensive list of the scheduled Materials for the Resource, including all relevant information for each one.

    • Production Order Step - displays a comprehensive list of the planned jobs, with information for each of the jobs regarding progress, due date, quantities and the Materials associated to each Production Order Step, including the state (displayed on the header bar of the information box).

  • Calendar view - displays a Gantt Chart that shows all the different Materials scheduled for the Resource, as well as any Material belonging to Production Order Steps.

    Info

    This view is very similar to the Schedule View available in the Schedule page. For more information, see Schedule Page.

  • Unplanned Materials - displays a list of Materials currently on the Resource but outside the defined Schedule.

Storage View#

For Resources of Processing Type Storage, a top-down view of the Resource is made available to you, displaying all the storage positions of the Resource, including information on the stored Materials or Containers for each position. You can zoom and drag the visualization and select each of the positions that are shown in grid form, with matrix-like indications of the storage positions.

This view is created from the information contained in the Resource. The number of Total Positions can be seen on-screen in a visual display of the combination of Storage Dimensions and the appropriate Dimension size, format and orientation. Maintenance#

The Maintenance view displays information on the Resource scheduled Maintenance Activity Orders.

Maintenance Activity Orders can be viewed both in calendar or list formats, allowing you to navigate through different dates and to apply various filters to visualize orders by Week, Month, or Day.

In this view, it is also possible to filter Maintenance Activity Orders by their name, Entity's name, or their system state.

Contexts View#

This view shows information concerning all the contexts currently connecting the Resource to other objects in the system:

  • Chart Context - displays the existing Relations between the Resource and any Chart existing in the system.
  • Checklist Context - displays the existing Relations between the Resource and any Checklist definition existing in the system.
  • Data Collection Context - displays the existing Relations between the Resource and any Data Collections existing in the system.
  • Document Context - displays the existing Relations between the Resource and any Documents existing in the system.
  • Ideal Cycle Time - displays the existing configurations for Ideal Cycle Time for all the Products related to this Resource.
  • Industrial Engineering - displays the existing configurations for Cycle Time calculations for the Product.
  • Replenishment Context - displays the contextual information on Replenishment Contexts for this Resource.
  • Substrate Map Bin Converter - displays the Substrate Map Bin Converter(s) related to this Resource.

Note

To be able to edit the data contained in the Context tables, you will need the ContextResolution.EditData security feature.

Compare View#

🔒 Resource.Compare

This view provides a quick visual comparison between the selected entity version and any other version that can be selected through it. You can also export the comparison results to a PDF file through the Export Comparison button on the top ribbon. For more information, see Compare Entity Versions.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Resource and other entities and enables you to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Resource and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Resource object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
