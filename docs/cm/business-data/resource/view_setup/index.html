View Setup#

🔒 Resource.ViewSetup

Overview#

This operation is used to View the setup for the processing of one Material at one Resource. This is only a visualization facility.

Note

This use-case can only be triggered from the Resource View as it requires both the context of a Material and a Resource.

For more information see, View Line Setup.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The applicable Resource exists, it is Active and the Processing Type is Process or Line.
  • The selected Material must exist and be Active, Queued or Dispatched, at the applicable Resource, and must be Top-Most.

Sequence of Steps#

Step 1: Resource#

  1. Select a Resource and then select View Setup.

  2. The Resource details will be displayed. Review the information and then Close.

Step 2: Documents#

Note

This Step is only available if there are Documents associated with the Resource.

  1. To open a document, you need to select it.

Step 3: Durables#

Note

This Step is only available if there are Durables required for the Material at the Step.

  1. In this step, you can view the details of the current Durables.

Step 4: BOM#

Note

This Step is only available if there is a BOM required for the Material at the Step and only if the Material is Top-Most.

  1. This step provides information about the current BOM, if any.

Note

If there is a BOM of scope Materials associated to a Material that has characteristics, the BOM will be displayed with the characteristics of the Material.

Info

BOMs are configured in the Step BOM Context.

Step 5: Recipe#

Note

This Step is only available if the Resource on which the Material is being tracked-in is configured to enable Recipe Management.

  1. This step is used to visualize the Recipe along with its parameter information.

Step 6: Instruments#

The system displays all the Parameters to be measured, showing which ones have at least one available instrument and which ones do not. A list of all attached instruments to the Resource is also displayed.

Note

Recipes are configured in the Service Recipe Context.
