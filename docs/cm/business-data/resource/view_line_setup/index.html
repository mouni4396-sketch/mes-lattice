View Line Setup#

🔒 Resource.ViewLineSetup

Overview#

This operation is used to View an ongoing setup in the Sub-Resource(s) of a Line Resource.

Note

This use-case can only be triggered from the Resource View as it requires both the context of a Material and a Resource.

For more information see, View Setup.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The main Resource is of processing type Line.
  • The Material must be tracked in.
