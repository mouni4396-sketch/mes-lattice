Manage Resource Recipes#

🔒 Resource.Edit

Overview#

This operation is used to manage the current Resource Recipes.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Resource must be active.
  • The Resource Track Resource Recipes property must be set to true.

Sequence of Steps#

On the right side of the screen, navigate to the Recipes section. The Manage Resource Recipes wizard can be opened by selecting the Manage button.

Step 1: Recipe Details#

  1. Choose a Resource Recipe.
  2. Define whether the Recipe is enabled for the Resource (defaults to true).
  3. Choose a Qualification Check for the Resource Recipe.
  4. Select Update to complete the operation.
