Manage Personnel#

🔒 Resource.Edit

Overview#

This operation is used to manage Personnel requirements, i.e, Employees' Certifications and Check-In and Check-Out information.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Labor Management module is properly licensed in the system.
  • The Employee exists and is Active.

Sequence of Steps#

Step 1: Check-In#

  1. Optionally, modify the Employee's Check-In options:

    • Enable Check-In - defaults to false. When set to true, all other options will be enabled.
    • Is Restricted - if the Resource has the property IsRestricted set to true, the user will then have to select the position in which he is checking-in.
    • Enforce Personnel Requirements at Track-In - when performing Track-In, the Employee will be asked for confirmation on Certifications and Qualifications.
    • Automatically Check-Out Employees at End-of-Shift - depending on the Shift defined for the Employee on the Shift Definition, if this option is set to true, Check-Out will be performed automatically at the end of the Employee's shift.

    • Require Check-In for Material Operations - if activated, this option will make it mandatory for the Employee to perform the Check-In operation on the Resource when executing Material-related operations, as follows:

      • Abort Material Process
      • Assemble Material
      • Replace Assembled Material
      • Track-In Material
      • Track-Out Material
      • Weigh & Dispense

    • Require Check-In for Resource Operations - if activated, this option will make it mandatory for the Employee to perform the Check-In operation on the Resource when executing Resource-related operations, as follows:

      • Begin Setup
      • Complete Setup
      • Manage Consumables
      • Manage Consumable Feeds
      • Manage Resource Durables
      • Manage Resource Instruments
      • Perform Setup

    • Employees can Check-Out others on Check-In - if set to true, the Employee can select another Employee who is already checked-in to replace his/her current position.

    • Log Check-In Activity - when set to true, a check-in log wil be kept, that can later be used for Reporting.

Step 2: Personnel Requirements#

  1. Add as many Employee Certifications as necessary, by selecting the button on the top right-hand corner of the screen or remove them if necessary, by selecting the button.

  2. For each of the Certifications, add the following information:

    • Name of the Certification.
    • Quantity - number of required Employees that hold the Certification.
    • Allocation - percentage of working time that is allocated to each Employee. A value of zero (possible) indicates zero allocation and a value of one indicates full allocation.

    • Allocation Type - used for Scheduling purposes in order to ascertain the possible employee allocation to a specific period of operation. Possible values are:

      • Process
      • Setup
      • SetupAndProcess (default)

      Info

      The Allocation Type does not affect or restrict employee operations involving the Material or Resource, such as Track-In, Perform Setup, Perform Data Collection, and other similar tasks.

    • Whether the Certification is Exclusive or not - defaults to false. In case you want the Certification to be exclusive for an Employee, the Allocation number will turn to 1.

  3. Select Update to complete the operation.

Info

The difference between Allocation and Quantity can be understood through the following example. In order to have one (1) Employee associated to the Resource, possible configurations can be:

Quantity Allocation
1 1
2 0.5 (50% availability for each employee)
4 0.25 (25% availability for each employee)
... ...
