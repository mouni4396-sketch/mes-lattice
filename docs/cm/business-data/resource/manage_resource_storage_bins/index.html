Manage Resource Storage Bins#

🔒 Resource.Edit

Overview#

This operation is used to manage the Storage Bins associated to a Storage Resource.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Resource must be active.
  • The Processing Type of the Resource must be Storage.
  • The Resource Enable Automatic Replenishment property must be set to true.

Sequence of Steps#

Step 1: Storage Bins#

Navigating to the Inventory section on the right hand side of the screen will scroll the page to the appropriate section and the Manage Storage Bins wizard can be opened by pressing the Manage button.

  1. Add as many Storage Bins as desired (select in the top right of the grid to add and to remove) and for each Storage Bin provide the following information:

    • The Storage Bin name - once the Bin is assigned, the Name cannot be changed.
    • Optionally, a description.
    • If the position unit type of the Resource is set to Material:
      • Specify the Product to which bin will be restricted. Alternatively, a Product Group can also be specified to restrict the contents of the bin.
      • Define if this bin is a preferred Storage Location for a particular Product or Product Group.
      • Define if the timer for the Floor Life is paused. This is valid for Resources of Processing Type StorageUnit and if the flag is set to false, the IsFloorSafe value from the Resource is used.
      • Optionally specify the Capacity Class (from the lookup table CapacityClass). This property is only used for scheduling purposes for Resources of type Tunnel and Batch.
    • If the position unit type of the Resource is set to Container:
      • Specify the Container Type of the Storage Bin.
    • Define whether the bin has limited positions. If so, define the number of Total positions. The number of Used positions will be displayed automatically.
    • Define whether the Storage Bin is enabled.

  2. Select Update to complete the operation.
