Manage Dimensions and Time Frames#

🔒 KPI.Edit

Overview#

This operation is used to modify the KPI's dimensions and time frames, i.e, the scope and time variations of the specific KPI.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The KPI exists and it is Active.

Sequence of Steps#

Step 1: Manage Dimensions#

  1. Add or remove the desired KPI dimensions by using the + and the remove buttons.
  2. For each added dimension, provide the following details:
    • Value Type - Whether the KPI calculation will return a single value or data series.
    • Source - The source of the KPI for calculated KPIs. If the selected source is Business Rule, select a Rule from the available options. If the selected source is Operational Data Store, Data Warehouse or Cubes, enter the Source Command.
  3. Select Next to define the KPI time frames.

Info

The main objective of the BI Cards functionality is to provide aggregated measures for dashboards visualizations. The Data Group functionality is not used for the calculations, therefore the displayed values are not dependent on individual user's Data Group permissions.

Info

The calculation of the BI Cards values are mainly done using pre-aggregated data from the Data Warehouse (DWH) or from the Operational Data Store (ODS) database. Each value is calculated by executing a direct query to the data. Please be aware that a poorly created query will impact DWH or ODS performance. Each created query must be tuned in order to guarantee optimal performance.

Step 2: Manage Time Frames#

  1. Add or remove the desired KPI new time frames by using the + and the remove buttons.
  2. For each newly added time frame, provide the following details:
    • The Entity's name.
    • Whether the time frame is the default one or not.
    • The From date and time.
    • The To date and time.
  3. Select Update to complete the operation.
