Generate Shift Plan Calendar Days#

🔒 ShiftPlan.GenerateCalendarDays

Overview#

The generation of Shift Plan Calendar Days generates individual Employee Calendar days for each Employee associated with the Shift Plan. It's based on the Employee associations with Team, Workgroup and Position and takes into account the Calendar Shift Definition Shifts and Teams for each Calendar Day.

Setup#

In order to be able to perform Generate Shift Plan Calendar Days it's necessary to:

  1. Have Calendar Days generated for the period where it's intended to create Shift Plan Calendar Days (please refer to Generate Calendar Days).
  2. Have the Employees associated with Shift Plan (please refer to Manage Employee Teams and Workgroups).

Preconditions#

  • The Shift Plan exists in the system and is Active.

Sequence of Steps#

The Generate Shift Plan Calendar Days wizard can be called from the Shift Plan page within the Business Data Group.

Step 1: General Data#

  1. Specify the start and end date. The system will present the number of Calendar Days to be generated.
  2. Select whether to override employee non-working days.
  3. Select whether to override employee non-working times.
  4. Select whether to override employee temporary assignments.
  5. Press the Generate button to complete the operation.
