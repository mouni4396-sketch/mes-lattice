Create Shift Plan#

🔒 ShiftPlan.Create

🔒 ShiftPlan.CreateTemplate

🔒 ShiftPlan.CreateFromTemplate

Overview#

This operation is used to create a shift plan, i.e. a step-by-step list of actions for the user. A template can also be created using a similar procedure and there is also the possibility of using a template to create the new object as well. This selection can be done in the main entity menu.

Preconditions#

  • The Shift Plan name must be provided and must be unique.

Sequence of Steps#

Step 1: General Data#

  1. Provide a name for the Shift Plan.
  2. Optionally, enter a description.
  3. Select the Shift Plan type. The list of possible values is taken from the lookup table ShiftPlanType.
  4. Select the Calendar for the Shift Plan.
  5. Select the Owner Role for the Shift Plan. Members of the Owner Role will be able to manage all the Calendar Days of the Shift Plan.

Step 2: Rules#

  1. Optionally, enter a list of Rules of scope ShiftPlanning to validate specific working time rules.

Step 3: Workgroups#

This screen is used to capture Shift Plan Workgroup information. Add, edit and remove Workgroups providing for each Workgroup:

  1. The name, which must be unique within the Shift Plan.
  2. Optionally, a description
  3. The Owner Role. Members of the Owner Role will be able to manage the Calendar Days of within the Workgroup.

Step 4: Workgroup Settings#

You can configure different settings for each Workgroup, namely:

  1. The Resources that belong to that Workgroup. A Resource can only be added one time to a Shift Plan and the Area Calendar of the Resource does not have to match the Calendar of the Shift Plan.
  2. Optionally, enter a list of Personnel Requirements by specifying a Position (a Certification) and a quantity.
  3. Optionally, a list of Steps with the respective Facilities that are part of the Workgroup. Note that the combination Step, Facility must be valid, that is, they must be connected by an Area and that the same Step, Facility combination must be unique in the same Workgroup.
  4. Select Create to complete the operation and the new Shift Plan will be created.

Info

It's possible to calculate the Workgroup Personnel Requirements based on the Resource Personnel Requirements (if defined) by pressing the right-arrow button.
