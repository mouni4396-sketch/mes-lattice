Create Inspection Order Samples#

🔒 Material.CreateInspectionOrderSamples

Overview#

This operation is used to create Material samples when the Inspection Order associated to the Material contains separate Inspection Steps.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Material exists, it is Active and the current System State is In Process.
  • The Material has an associated Inspection Order with the property Has Separate Inspection Steps set as true.

Sequence of Steps#

This screen captures all the necessary information for the transaction.

  1. Select an appropriate Material. Access the Create Samples menu option from the More dropdown menu, located at the top ribbon.

  2. Review the information about the new sample number and the quantities to be created, as well as the Step where they will be sent.

    Info

    Samples for all Inspection Plan Steps with Split Mode equal to CreationStep must be created in full.

  3. Select Create to complete the operation.
