Reprint Material Documents#

🔒 PrintableDocument.Reprint

Overview#

This operation allows you to reprint printable documents configured for the Material.

Setup#

To be able to reprint a document for a Material it is necessary to:

  1. Have a Printable Document that is created and effective and that applies to Material. For more information on how to create a Printable Document, please refer to the section Printable Document.
  2. Define the necessary context in the smart table MaterialPrintableDocumentContext. To define a default document to generate a Lot Traveler or Label, it is necessary to edit the smart table AreaPrintableDocumentContext.

Preconditions#

  • Material exists and it is not a Template.
  • Material has a Printable Document associated to it.
  • Material has a print history of Printable Documents.
  • Details of the Printable Document must have Store Print History and Store Layout History set to True.
  • If there are Data Contexts for the Printable Document they must have Store Print History set to True.

Sequence of Steps#

Reprint Documents for Material#

The Reprint Documents wizard will show a document or a list of documents that are associated to the Material and that are able to be reprinted.

Step 1: Documents#

  1. Select the document(s) to be reprinted by selecting the respective checkbox(es).
  2. Optionally, enter a comment.

  3. Select Next to continue.

Step 2: Printer#

  1. Select the print option:

    • Original
    • New Printer - you must configure the printer in the PrinterTypePrintersContext Smart Table.

    Info

    Only documents for which the Printing Integration is null can be printed to a different printer. All documents for which a Printing Integration is set, must use the original Printer.

    Note

    If multiple documents to reprint have been selected, a New Printer can only be set if the Printer Type of all the selected documents is the same.

  2. Specify the number of copies (defaults to 1) to reprint.

    Note

    Only documents for which the Printing Integration is null can have a user defined number of copies. All documents for which a Printing Integration is set, must use the original number of copies.

  3. By selecting the Preview button, it is possible to visualize the document before it is reprinted.

  4. Optionally, enter a comment.

  5. Select Reprint to complete the operation.
