Update Material Process Progress#

🔒 Material.UpdateProcessProgress

Overview#

This operation is used to manually update (or through automation) the Material process progress for the purposes of visualization or alarming.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Material exists, it is Active and the current System State is Dispatched or In Process.
  • The Material is a Top-Most Material.

Sequence of Steps#

This screen captures all the necessary information for the transaction.

  1. Select an appropriate Material. Access the Update Process Progress menu option from the More dropdown menu, located at the top ribbon.

  2. All values for process progress are optional:

  3. Progress (in percentage, displayed as a slider bar)

  4. Quantity to Process
  5. Processed Quantity
  6. Loss Quantity
  7. Quantity Units
  8. Job Id
  9. Original Planned Start Date
  10. Planned Start Date
  11. Start Date
  12. Original Planned End Date
  13. Planned End Date

  14. End Date

  15. Press Update to complete the operation.
