Print Material Documents#

🔒 PrintableDocument.Print

🔒 PrintableDocument.PrintLotTraveler

Overview#

This operation is used to print the Lot Traveler or other documents configured for the Material in the Step.

Setup#

To be able to print a document for a Material it is necessary to:

  1. Have a Printable Document that is created and effective and that applies to Material. For more information on how to create a Printable Document, please refer to the section Printable Document.
  2. Define the necessary context in the smart table MaterialPrintableDocumentContext. To define a default document to generate a Lot Traveler or Label, it is necessary to edit the smart table AreaPrintableDocumentContext.

Preconditions#

  • Material is Active.
  • At least one Printable Document is Active, Effective and is associated with the Step.

Sequence of Steps#

Print Documents for Material#

Step 1: Documents#

The Print Documents wizard will show a document or a list of documents that are associated to the Material and that are able to be printed.

  1. Select the documents to be printed by ticking the respective checkbox(es) and select Next.

Step 2: Context#

This screen is used to capture all the necessary input information for the selected Printable Documents.

  1. Depending on the selected documents, the inputs need to be provided for all selected Printable Documents. Provide all required inputs, such as Step and Flow.
  2. Select Next.

Step 3: Printer#

  1. Select the printer and add the number of copies you want to print.
  2. By selecting the Preview button, it is possible to visualize the document before it is printed.
  3. Select Print to complete the operation.

Print Lot Traveler for Material#

  1. To print a lot traveler document, select the Print button on the Material bar and then select Lot Traveler.
  2. When the wizard is displayed, proceed to selecting the printer and choosing one of the available options:
    • All Facilities - prints the lot traveler for all the Facilities.
    • Complete Flow - prints the lot traveler for all the remaining Flow.
    • Current Area (default option) - prints the lot traveler for all the remaining Flow Steps in the current Area.
    • Current Step - prints the lot traveler only for the current Material Step.
  3. By selecting the Preview button, it is possible to visualize the lot traveler document before it is printed.
  4. Select Print to complete the operation.

Print Label for Material#

  1. To print a label for a Material, select the Print button on the Material bar and then select Label.
  2. When the wizard is displayed, choose an available printer.
  3. By selecting the Preview button, it is possible to visualize the label document before it is printed.
  4. Select Print to complete the operation.
