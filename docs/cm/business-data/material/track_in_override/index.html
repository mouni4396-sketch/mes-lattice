Track-In Override#

🔒 Material.TrackInOverride

Overview#

This operation allows the user to perform a Track-In of a Material which is not the next Material in the Resource schedule sequence. If called from either the Material page, or in the Step View of the FabExplorer, it also allows the user to Track-In the Material to another Resource.

Pre-conditions#

The pre-conditions for Track-In also apply for Track-In Override with these differences:

  • The Resource must be of Dispatch Schedule Type Scheduling.
  • The Material must be referenced in a schedule job with System State Ready, which is not yet started and scheduled for a Resource.
  • Contrary to Track-In, it is possible to track-in any Material in its schedule sequence.

Info

To check the Track-In operation's pre-conditions, please refer to the Track-In operation page.

Sequence of Steps#

If accessed from the Material Page (for Resource reallocation and/or sequence override)#

Step 1: Resource#

This screen gives the user the choice to change the Resource to which the Material is allocated.

  1. In the available Resources section, select the Resource to which the Material should be allocated.
  2. In the Resource Details tab, validate the details for the selected Resource.

Step 2: Resource State#

This screen allows the user to set the a new State for the Resource.

  1. In the Resource Details tab, it is possible to see again the details for the Resource.
  2. In the Resource State tab, it is possible to set a new state for the Resource.
  3. Optionally, enter a Comment.
  4. Press Track-in to complete the Track-In Override process.

Info

Similarly to Track-In, other screens may appear depending on the configuration, such as screens related to BOMs, Documents, Checklists, among others. For more information on these screens, please refer to the Track-In operation page.

Info

If accessed from the Step View of the FabExplorer (for Resource reallocation and/or sequence override)

The step sequence for Track-In Override in the Step View of the FabExplorer is the same as in the Material page (detailed previously).

If accessed from the Resource View of the FabExplorer (for sequence override)#

Step 1: Resource#

This screen shows the user details regarding the Resource to which the Material is allocated.

  1. In the Resource Details tab, it is possible to see the details for the Resource.

Step 2: Resource State#

This screen allows the user to set the a new State for the Resource.

  1. In the Resource Details tab, it is possible to once again see the details for the Resource.
  2. In the Resource State tab, it is possible to set a new state for the Resource
  3. Optionally, enter a Comment.
  4. Press Track-in to complete the Track-In Override process.

Info

Similarly to Track-In, other screens may appear depending on the configuration, such as screens related to BOMs, Documents, Checklists, among others. For more information on these screens, please refer to the Track-In operation page.

Info

For more information on how to navigate the FabExplorer, please refer to the FabExplorer page.

Info

If a Production Order Step exists for this Resource and is currently in state In Progress, the Production Order Step In Progress Quantity will be set to InProgressQuantity + Material Primary Quantity + Material SubMaterialsPrimaryQuantity. If the state of the Production Order Step is Released, it will be set to In Progress.
