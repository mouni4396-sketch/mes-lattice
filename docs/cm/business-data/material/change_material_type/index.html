Change Material Type#

🔒 Material.ChangeType

Overview#

This operation is used to change the Material type.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • Material exists and is Active.
  • The new Material Type exists in the MaterialType Lookup Table.

Sequence of Steps#

  1. Optionally, review the Material details by expanding the Material section.
  2. Select a new Type for the Material. This must be a value from the MaterialType Lookup Table.
  3. If the Material has Sub-Materials, it is possible to check the option to change the Type of all Sub-Materials that have the same Type as the parent Material.
  4. Select Change to complete the operation.

Info

If no Type is changed, an error will be returned.
