Compose New Material#

🔒 Material.ComposeNew

🔒 Material.Create

🔒 Material.CreateTemplate

🔒 Material.CreateFromTemplate

Overview#

This operation is used to create a Material, while also creating its Quantities or Sub-Materials in a single operation. For more information, see Create Material, Compose Material (Quantities), and Compose Material (Sub-Materials).

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Info

This transaction is relevant for genealogy.

Sequence of Steps#

To Compose a New Material, access the Compose New button on the top ribbon and choose the desired mode: From Quantities or From Sub-Materials.

Mode: Quantities#

  1. Create a Material. Follow the same steps as described in the Create Material operation.

  2. Choose the Materials to compose by selecting the icon. For each Material, specify the Primary and, if defined, the Secondary Quantities. It is also possible to remove the Materials by selecting the icon. To perform the transaction, it is necessary to select at least one Source Material.

    Note

    The final Primary and Secondary Quantities (if defined) are automatically updated to reflect the Composed Quantities.

  3. Optionally, enter a comment.

  4. Select Create to complete the operation.

Mode: Sub-Materials#

  1. Create a Material. Follow the same steps as described in the Create Material operation.

  2. Optionally, select a BOM of Compose Map scope.

  3. Optionally, select a Target Container.

  4. Select Next to continue.

  5. Select the Source Parent Materials that will be transferred to the Target Container. You may select as many as you wish.

  6. Select Next to continue.

  7. Depending on your selections in steps 2 and 3, follow the steps described in Sub-Materials Transfer.

  8. Select Create to complete the operation.
