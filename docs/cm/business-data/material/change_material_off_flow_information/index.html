Change Material Off-Flow Information#

🔒 Material.ChangeOffFlowInformation

Overview#

This operation is used to change the Material Off-Flow Information, usually to correct a mistake. It includes cancelling Rework or Temporary Off-Flow and changing the Return Flow Paths.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Material exists and it is Active, not OnHold and not InTransit.
  • The Material is Queued and is Topmost (that is, it has no Parent).
  • The Material is in an Off-Flow state.

Sequence of Steps#

Step 1#

  1. Select a Material.
  2. The Material Off-Flow Information can be edited in the following manner:
  3. The Material Rework Stack Information is displayed - including information about whether it is a Rework or an Off-Flow. The user can then:
    • Change the Return Flow Path of any layer of the Rework Stack by specifying any Flow Path of the return Flow - only for ReworkPaths of type Rework.
    • Clear one or more Rework levels - but the clearance must always come from the top to the bottom (like a stack) - note that this applies both to ReworkPaths of type Rework and Off-Flow.
    • For Off-Flows of type Rework: the Return Flow Path can be edited by selecting a new Return Flow Path.
  4. Optionally, enter a comment.
  5. Press Change to complete the operation.
