Track-In Material for Maintenance#

🔒 Material.MaintenanceTrackIn

Overview#

This operation is used to track a Material into a Resource that is currently with System State Down or On Hold for Maintenance.

Tip

This operation is not available when the Maintenance Type of the selected MAO is set to Qualification.

Setup#

No setup is required other than to meet the preconditions of the transaction.

Preconditions#

Same preconditions as Track-In Material, with the following extra conditions:

  • If the Resource on which the Material will be tracked-in has the Dispatch Schedule Type property set to Scheduling, the Material must be in state Queued. If the Dispatch Schedule Type property is set to Dispatching, the Material must be in state Queued or Dispatched.
  • If a MAO Owner Employee is defined, the current user must be associated with that Employee. Alternatively, if a MAO Owner Role is defined, the current user must belong to that Role.
  • The Maintenance Type of the selected MAO must not be set to Qualification.

Sequence of Steps#

There are several possible ways to perform this operation, depending on the starting point:

From Material#

Select an appropriate Resource (with open MAOs in state In Progress that have the Material Type Restriction Mode property as Allow All or with a Material Type that matches the Material Type of the current Material and the Material Type Restriction Mode is set to Allow Specific).

Info

If the Material is already dispatched to a Resource, that Resource will be automatically selected.

After selecting the Resource, select an appropriate MAO (from any open MAOs on the Resource, in state In Progress that have the Material Type Restriction Mode property as Allow All or with a Material Type that matches the Material Type of the selected Material and the Material Type Restriction Mode is set to Allow Specific):

From Resource#

Select an appropriate MAO and Material (from any open MAOs on the Resource, in state In Progress that have the Material Type Restriction Mode property as Allow All or with a Material Type that matches the Material Type of the selected Material and the Material Type Restriction Mode is set to Allow Specific)

After selecting the MAO, select an appropriate Material (with the Material Type Restriction Mode property as Allow All or with a Material Type that matches the Material Type of the selected Material and the Material Type Restriction Mode is set to Allow Specific):

From MAO#

Select an appropriate Material (with the Material Type Restriction Mode property as Allow All or with a Material Type that matches the Material Type of the selected Material and the Material Type Restriction Mode is set to Allow Specific)

After selecting the appropriate entities, review the information and select Track-In to complete the operation.
