Perform Material Checklist - New#

🔒 Material.PerformChecklist

Overview#

This transaction is used to perform a long running Checklist for a Material that has been opened during the Track-In. Because the Checklist is Long Running, it may be performed over a long period of time.

Setup#

  • It is necessary to create a Checklist with execution mode Long Running and scope Material Tracking and then associate it to the Step using the Step Checklist Context.
  • If the Checklist has a Data Collection you need to associate it to the Step in the Material Data Collection Context Smart Table.
  • If the Checklist has a BOM you need to associate it to the Step in the BOM Context Smart Table.
  • At Track-In, the Checklist Instance will be created, and only after the Checklist has been completed, it will be possible to Track-Out the Material.

Preconditions#

The Material has a Long Running Checklist in state Open.

Sequence of Steps#

Step 1#

  1. Select Perform New on the top ribbon.

  2. Complete the checklist item by item, and remember that some checklist items:

    • Are optional.
    • May be floating, which means that they can be executed at any time.
    • May have parameters.
    • May require an electronic signature, if the Material.PerformChecklist security feature has the Force Signature option set to true.
    • May have data collection parameters, and you can post the data directly on the wizard below when using the Modern interface.
    • May have BOM products.
    • May have a documentation URL.
    • May have a note, which can be edited.

    Info

    Instructions for the Checklist/Data Collection can be toggled on and off by selecting the icon next to the respective item/Parameter. Once all mandatory fields are filled, a icon will appear alongside the Parameter. If you choose the Modern interface when creating the Data Collection, you will have the option to input data directly on the page below. To find out more, please see Create Data Collection.

Note

In terms of the BOM Products, the behavior is defined by the scope of the BOM associated with the Checklist. Also, more than one Material can be added to fulfill the required quantity. You can add new Materials by selecting the ADD icon and remove them by selecting the icon after each Material. All Materials must be valid and meet the criteria for assembly as stated in Assemble Material.

In addition, some Checklist instances may have documents attached to the Main Material, Product of the Main Material, and the Product of the BOM items.

During the Perform New operation, if a CAD file is associated with the Product of the Material, you can view the CAD model by selecting View CAD in the top ribbon. This will open the model in the CAD Viewer, as displayed in the figure below.

For information on how to associate a CAD file with a Product, see CAD File Support.
