Track-Out and Material Move-Next#

🔒 Material.TrackOutAndMoveNext

This wizard combines the Track Out and Material Move Next functionality in a single transaction

For more information, please refer to the Track Out and Material Move Next wizards information.

Info

If the Track-Out and Material Move Next by Default flag is true for a given Step, in Step View, Resource View and Material Details, the Track-Out and Material Move Next operation remains in the ribbon and the Track-Out operation is moved to the More section of the ribbon. If the Track-Out and Material Move Next by Default flag is false, the Track-Out operation will remain in the ribbon and the Track-Out and Material Move Next is moved to the ribbon.

Warning

In order to configure a Checklist or Data Collection to be used on any of the operations and the system currently has Track-Out and Move-Next combined as a single transaction, the configuration in the appropriate context table must specify the first operation (Track-Out) as the trigger operation so that it is displayed appropriately. For more information, see MaterialChecklistContext or MaterialDataCollectionContext.
