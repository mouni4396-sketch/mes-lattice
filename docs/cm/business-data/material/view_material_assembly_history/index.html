assembly

View Assembly History#

Overview#

This operation is used to view the full Material Assembly History for a given Material. It will include a list with all the BOM Instance Items, and a list of all BOM Items and Materials for a given Material.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The assembled Material exists (or is terminated) and is not a template.

Sequence of Steps#

  1. Select a Material and select the Assembly History section on the right.

  2. The system will display two lists: one showing BOM Items and another showing Materials:

  3. Depending on the columns you have selected to be displayed, in the BOM Items list you can see the following details:

    • Actual Quantity
    • Assembled Quantity
    • Assembly Type
    • BOM Instance
    • BOM Instance Edit State
    • BOM Instance State
    • Facility
    • Flow
    • Modified On
    • Product
    • Product Description
    • Required Quantity
    • Resource
    • State
    • Step
    • Units

    Info

    You can filter this list by Step, Product or Material. Additionally, you can filter by Incomplete BOM Items - these are items where the Actual Quantity is less than the Required Quantity, but the difference is small enough to be within the Acceptable Rounding Error. This value can be changed using the configuration key /Cmf/System/Configuration/MaterialTracking/Assemble/AcceptableRoundingError, which defaults to 0.

  4. For each of the BOM Items you can drill down to see the Materials that were consumed and other information depending on the column you have selected for this view:

  5. Alternatively, you may prefer to view the list with all the Materials of the BOM Instance Items, which depending on the columns you have selected, displays the following information:

    • Information Name
    • Information Value
    • Material
    • Material Type
    • Modified On
    • Operation
    • Product
    • Product Description
    • Quantity
    • Sequence

    Info

    This list holds the same information as the second level of the table, the only difference is that it is a flat list of the Materials.

    Additionally, you can filter this list by Product and Material.

  6. Should you want or need to Add, Replace or Remove Assembly History Items, please see Update Assembly History.

Note

The BOM items lists will not show any BOM instance with system state Open or universal state Terminated (indicating that the BOM instance was aborted).
