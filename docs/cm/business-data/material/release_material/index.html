Release Material#

🔒 Material.Release

Overview#

Releases a Material from one or more Hold Reasons.

Info

This transaction is available for multiple Materials from the Resource and Step View. For more information, see the FabExplorer page.

You can also Mass Release Materials from the Quality menu, by selecting the Material Holds entity. For more information, see Mass Release Materials.

Supports Smart Barcodes

You can use Smart Barcode Scanning to perform this operation.

Setup#

No special setup is required other than to meet the transaction preconditions.

Preconditions#

  • Material is Active and On Hold.
  • Material is currently on Hold for the Reasons it is being released from.
  • If a Release Role is associated with the Hold Reason, the user performing the Release Material must belong to that Role.

Sequence of Steps#

Step 1#

This step contains all the necessary information to perform the transaction.

  1. Optionally, review the Material details by expanding the Material section.
  2. Select the Reasons from which the Material is to be released from, by selecting the respective checkboxes. You can also select them all by selecting Materials in the header of the column.
  3. If a Material has a Release Code set, it is necessary to enter the Release Code in order to be able to release the Material.
  4. Optionally, select the Apply to All button. This button will only be active if there is more than one valid reason and if selected, properties will be copied to other reasons.
  5. Optionally, enter a Comment.
  6. Select Release to complete the operation.

Info

Hold codes which are presented in red lines mean that the current user does not belong to the security role which has the privileges to release the Material from that Hold Reason.

Info

If the Release Code has been forgotten, with the right privileges it is possible to use the Special Release Material transaction.
