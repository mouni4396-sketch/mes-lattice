Dispatch Material#

🔒 Material.Dispatch

Overview#

This operation is used to assign a Material to be processed at a certain Resource. It acts as a Material reservation for a given Resource. A Resource can be any Resource - physical or virtual. This transaction is available for multiple Materials from the Resource and Step View.

Supports Smart Barcodes

You can use Smart Barcode Scanning to perform this operation.

Setup#

To enable the dispatch of a Material to a Resource it is necessary to:

  1. Have a Resource of Processing Type Process with a Service associated and enabled in the same Facility of the Material. The Resource must be dispatchable.
  2. The Material required Service (the Service Context defined at the Step level) at its current Step must match the Service defined in 1.

Note

The Service must be enabled globally, and the Material must be dispatchable.

Preconditions#

  • The Material exists and is Active.
  • The Material is not On Hold and not In Transit.
  • The Material is Dispatchable and Queued.
  • The Material is a Top-Most Material, that is, it has no Parent Material defined.

  • If the Bypass Future Actions And Experiment Locks property is not set to true:

    • The Material must not have a Required Future Action defined.
    • The Material Experiment Lock Type must either be set to null or to Move Next.

  • The Material and Resource are at the same Facility and Step.

  • The Resource exists, is Active, and is Dispatchable.
  • The Resource is a Top level Resource, that is, it has no Parent Resource and the Processing Type is Process or Line.
  • The Step is not a Pass-Through Step.
  • The Material must have the Current Material Transfer property set to null.
  • The Resource Dispatch Scheduling Type must be Dispatching.
  • The Resource has Lane Count > 0 and has Is Multilane Active set to true, in this case a valid Lane of the Resource must be provided.
  • The Materials are dispatched to the same Resource and Lane.
  • The Resource position management must be automatic.
  • The Resource must have the Inventory Locked property set to false.

Preconditions for Bulk#

  • In addition to the preconditions mentioned above, all Materials must:

    • Be at the same Facility.
    • Be dispatched to the same Resource and Lane.
    • Have the Track Positions property in the Resource set to false, or have both the Track Positions and the Auto Generate Positions properties set to true.

Sequence of Steps#

The Material can be dispatched from the perspective of the Resource or from the perspective of the Material.

Perspective of the Material#

This step is used to select the Resource for which to dispatch the Material.

  1. Optionally, review the Material details by expanding the Material section.
  2. In the Available Resources list, choose a Resource to dispatch the Material to.

  3. If the Material Required Setup is different from Not Required, the system will display a visual indicator, and filter (SETUP READY), so you can select Resources that do not need a setup before processing:

  4. In the Resource Details section, review the information related to the chosen Resource.

  5. If the Resource has Lanes configured, select a valid Lane of the Resource.
  6. In the Resource Order, choose the Queue Order for the Material: First or Last, whether a LIFO (Last-In, First-Out) or a FIFO (First-In, First-Out) logic is desired, respectively. FIFO is chosen by default.
  7. If the Resource does not auto-manages its positions, it is necessary to specify the position of the Material (if the Resource capacity is expressed in Materials) or the position(s) of the Material Container(s) (if the Resource capacity is expressed in Containers) in the Resource. The position(s) reflects a physical location.
  8. Optionally, add a Comment.

  9. Select Dispatch to complete the operation:

Perspective of the Resource#

This step is used to select a Material to dispatch in the current Resource.

  1. Optionally, review the Resource details by expanding the Resource section.
  2. If the Resource has Lanes configured (Is Multilane Active enabled), select a valid Lane of the Resource, and then select Next.
  3. Select the Material to be dispatched.

  4. If the Resource Setup Mode is different from Not Required, the system will display a visual indicator, and filter, so you can select Materials that do not need a setup before processing:

    In this filter you can also select to only see Setup Ready Materials:

  5. In the Material Details section, review the information related to the chosen Material.

  6. In the Resource Order, choose the Queue Order for the Material: First or Last, whether a LIFO (Last-In, First-Out) or a FIFO (First-In, First-Out) logic is desired, respectively. FIFO is chosen by default.
  7. If the Resource does not auto-manages its positions, it is necessary to specify the position of the Material (if the Resource capacity is expressed in Materials) or the position(s) of the Material Container(s) (if the Resource capacity is expressed in Containers) in the Resource. The position(s) reflects a physical location.
  8. Optionally, add a Comment.

  9. Select Dispatch to complete the operation:

Note

If the Material is In Store, it will be automatically retrieved from store.
