Edit Inspection Order Note#

🔒 InspectionOrder.Edit

Overview#

This operation is used to edit the note associated to an Inspection Order object.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Inspection Order exists in the system.

Sequence of Steps#

The Edit Inspection Order Note wizard can be called from the Inspection Orders page under the Quality menu, after selecting a specific Inspection Order.

Step 1: General Data#

Edit the note using the WYSIWYG text editor. Press Update to perform the operation.

Warning

The Name of the Inspection Order cannot be altered.
