Sort Rule Set#

🔒 SortRuleSet.Show

Overview#

A Sort Rule Set is a collection of Sort Rules which are used for sorting Material or Resources for dispatching purposes. It supports both the Push and Pull dispatching approaches.

System Sort Rules#

Property Scope Description
StandardSchedulingMaterialSorting Material Sorts Materials according to their planned start date order defined in the released Schedule Scenario, placing unscheduled Materials last.
StandardSchedulingResourceSorting Resource Prioritizes the Resource assigned to the current Material in the released Schedule Scenario.

Sequence Of Steps#

The necessary steps for correctly using a Sort Rule Set are the following:

  1. Create the necessary Sort Rules upfront - note that for creating custom rules, a Dynamic Execution Engine (DEE) rule is necessary. Note also that the application provides a set of pre-defined rules.
  2. Create a Sort Rule Set.
