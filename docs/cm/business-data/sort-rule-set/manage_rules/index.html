Manage Rules#

🔒 SortRuleSet.Edit

Overview#

This operation is used to Manage Rules of a Sort Rule Set.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Sort Rule Set exists in the system.

Sequence of Steps#

The Manage Rules wizard can be called from the Sort Rule Set page within the Business Data Group.

Step 1: General Data#

  1. Select the Rules section in the Sort Rule Set page.
  2. Select Manage to call the Manage Rules wizard.
  3. Add as many entries as you need (select in the top right of the grid to add and to remove). You can order the Rules with the and arrows, and provide the following information for each rule:
    • Rule (name)
    • Description
    • Sorting - Ascending or Descending
  4. Optionally, enter a comment.
  5. Select Update to complete the operation.
