Update Substrate Map Overlay#

🔒 SubstrateMap.UpdateOverlay

🔒 SubstrateMap.UpdateOverlayState

Overview#

This operation is used to update a new Substrate Map Overlay version.

Preconditions#

  • The Substrate Map exists and is Active in the system.
  • The Substrate Map Overlay must exist in the system and the type must be Bin Code Map.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Sequence of Steps#

The Update Overlay wizard can be called from the Substrate Map page within the Business Data Group. In Views, select Content, select an Overlay of type BinCodeMap, and then select the Update Overlay button on the top ribbon.

  1. Configure the optional settings for the Overlay:

    • Synchronize Quantity - enables synchronization of the Substrate Map Overlay with the Material quantity. For more information, see Set Material Substrate Map. If enabled, Step 2: Synchronization will be available.

      Note

      You can define the default value for the Synchronize Quantity by editing the entry Context = SubstrateMap.UpdateOverlay for the Element = Synchronize in the GUIElementDefaultValue Generic Table.

  2. Optionally, update the following information:

    • Facility - choose a Facility for the existing Overlay.
    • Step - choose a Step for the existing Overlay.
    • Resource - choose a Resource for the existing Overlay.
    • Class - add a Class for the existing Overlay.
    • Creation Date - choose a creation date for the existing Overlay.
