Edit Substrate Map#

🔒 SubstrateMap.Edit

Overview#

This operation is used to edit a Substrate Map object.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Substrate Map exists in the system and it is in the Active state.

Sequence of Steps#

The Edit Substrate Map wizard can be called from the Substrate Map page within the Business Data Group.

Step 1: General Data#

All non-system properties can be changed in this wizard.

The Name of the Substrate Map cannot be altered.
