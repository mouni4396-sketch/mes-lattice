View Device Bin Code History#

🔒 SubstrateMap.BinCodeHistory

Overview#

The View Device Bin Code History page allows you to retrieve and review the historical Bin Code information associated with a device. All Bin Code changes are securely stored indefinitely, ensuring full traceability and data availability for audits, quality control, and in the event of customer complaints.

Setup#

No specific setup is required other than to meet the preconditions of the operation.

Preconditions#

  • The Mapping module must be properly licensed.
  • The Substrate Map name must be unique.

Sequence of Steps#

Step 1: General Data#

  1. In the Substrate Map entity page, select the Device History button to open the View Device Bin Code History page.
  2. Enter a Device Id or a Lot Id, choosing to show All Values or only the Last Value.

  3. Optionally, select the icon to apply one or more advanced filters for more detailed results:

    • Enterprise
    • Site
    • Facility
    • Step
    • Date From
    • Date To
    • Map Name
    • Map Version
    • Layout Specifier
    • Substrate Type
    • Substrate Id

  4. Select Search to view the device history.

Data Grid Customization

You can customize the properties shown in the data grid by selecting the icon. For more information, see Data Grid.
