Manage Substrate Map Overlay Information#

🔒 SubstrateMap.ManageOverlayInformation

Overview#

This operation is used to define and manage the Overlay Information of the Substrate Map.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Substrate Map is created and is Active.

Sequence of Steps#

The Manage Overlay Information wizard can be called from the Substrate Map page within the Business Data Group. In Views, select Content, choose an Overlay, and then select the Manage Overlay Information button on the top ribbon. In the wizard:

  1. Add as many entries as you need (select on the top right of the grid to add and to remove), and for each Attribute provide the following information:

    • Name
    • Data Type
    • Value

    Info

    Each Attribute works as a way of capturing situations that occur in the workflow.

  2. Optionally, enter a comment.

  3. Select Update to complete the transaction.

The entered information will be available in the Overlay section (right panel):

It will also be available in the Details page of the Substrate Map in the Overlay Information section. Additionally, from here, if you select the Overlay, the Manage Overlay Information button is displayed, and you can manage information as mentioned above:

Note

The information is grouped by Overlay. For Overlays with defined Attributes, a hyperlinked number appears in the last column. Select this link to expand the Overlay and view its Attributes.
