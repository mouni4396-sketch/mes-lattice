View Device Genealogy#

🔒 SubstrateMap.Genealogy

Overview#

This operation is used to view the genealogy of a device through the Device Genealogy button. It can be used to view and retrieve the Backward (where it came from) and Forward (where it was used) device information.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Mapping module must be properly licensed.
  • The Substrate Map name must be unique.

Sequence of Steps#

Step 1: General Data#

  1. In the Substrate Map entity page, select the Device Genealogy button to access the View Device Genealogy page.

  2. Enter a Device Id, which can be obtained by selecting an individual unit in the Substrate Map page.

  3. Select Backward (where it came from) or Forward (where it was used) genealogy.

  4. Select Search to retrieve the genealogy data.

    Data Grid Customization

    You can customize the properties shown in the data grid by selecting the icon. For more information, see Data Grid.

  5. To download the results, select Export from the ellipsis menu in the lower-right corner of the page and export the data as a CSV file.
