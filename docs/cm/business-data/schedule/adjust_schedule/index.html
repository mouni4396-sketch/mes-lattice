Adjust Schedule Job#

🔒 Schedule.Create

Overview#

This operation allows a user to manually adjust a certain Schedule Scenario Job.

Info

For more information on Schedule Scenario Jobs, see the Jobs page in the Scheduling tutorial.

Preconditions#

  • The Schedule Scenario Job belongs to a released Schedule Scenario.

Sequence Of Steps#

  1. Choose a Schedule Scenario Job on the Schedule View of a released Schedule Scenario.
  2. Select the Adjust button on the top ribbon.
  3. Optionally, change the Resource to which the Schedule Scenario Job is assigned. Note that if another Resource is changed, it must also be compatible with the Schedule Scenario Job.
  4. Define either the new planned start time or planned end time for the Schedule Scenario Job. By changing one, the other is automatically recalculated according to the duration.
  5. Select the Adjust button to complete the operation.
