Unterminate Package#

🔒 Package.Unterminate

Overview#

This operation is used to Unterminate a Package.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Package exists in the system and it is Terminated.
  • The Package is Top Level.
  • In case an empty Package exists and must be terminated. The system must ensure the following:
    • The Package is of Content Type Package.
    • The Package does not contain any Children Package (Sub-Packages Count equals zero).

Sequence of Steps#

The Unterminate Package wizard can be called from the Package page within the Business Data Group.

Step 1: General Data#

  1. In the More button on the top ribbon, select Unterminate to perform the operation. All generic/smart table rows that reference this object will not be recovered.

Info

For more information, see Terminate and Unterminate.
