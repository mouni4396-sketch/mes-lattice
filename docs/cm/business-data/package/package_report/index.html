packing reports

Package Report#

Description#

This report provides information about a specific Package.

Data Source(s)#

  • ODS database

Assumptions#

  • None

Filters#

  • None

Header#

  • Line 1: Package Name and (Package Type) - The name and type of the package
  • Line 2: Content Product and (Content Product Description) - The product of the packages
  • Line 3:
    • Total Package Quantity - The total quantities of packages
    • Total Packed Quantity - The total packed quantity for the current package plus the sub-packages and unit information
    • Total Weight - The total weight for the current package plus the sub-packages and unit information

Fields for Level 1#

  • Package Qty (package is not trackable) or Package ID (package is trackable) - When package is not trackable Package Qty information is available, when package is trackable Package ID information is available
  • Content Product - The product of the package
  • Content Product Description - The product description
  • Material - The list of materials of the package
  • Packed Qty - The packed quantity with units information

Fields for Level 2#

  • Package - Sub-package name
  • Package Qty - Total packed quantity (current package and sub-packages)
  • Content Product - The content product of the package with revision/version information
  • Content Product Description - The content product description

Footer#

The footer contains information on the source of data, the date and time of when the Report was generated, the disclaimer, and the number of pages the Report has.
