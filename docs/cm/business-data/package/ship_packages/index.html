Ship Packages#

🔒 Package.Ship

Overview#

This operation is used to Ship a Top-Level Package that may contain different Materials.

You can Ship Packages from the Package entity in the Business Data menu or from the Packages entity in the Planning and Logistics menu.

The difference is that from the Planning and Logistics menu you can ship more that one package at a time, whereas from the Package entity in the Business Data menu, you have to ship one package at a time.

Info

For more information, see Packing.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Material Logistics module is properly licensed in the system.
  • The Package exists in the system and is Active.
  • The Package it Top-Level and the Parent Package is empty.
  • For all Packages:
    • The Content Type is Package.
    • The Sub-Package Count is greater that zero.
    • The System State is Closed.
  • All Materials that are part of the Packages must be at the same Facility.

Sequence of Steps#

The Ship Package operation can be called from the Package page within the Business Data Group.

Step 1: General Data#

  1. Select the Package entity, and open the package you want to ship:

  2. Select the Ship Package button on the top ribbon.

  3. Verify the Material information.
  4. Select the Facility to which the Material should be shipped.
  5. Optionally, enter or select an existing shipping label.

  6. Select the Ship Containers option (defaults to True) to ship the Containers along with the Material.

    Note

    This setting applies to all Containers of the Sub-Materials as well.

  7. Optionally, enter a comment.

  8. Select Ship to complete the operation.

  9. The Materials are shipped.

For more information see Ship Material.
