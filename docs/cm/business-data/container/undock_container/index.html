Undock Container#

🔒 Container.Undock

Overview#

This operation is used to decouple a Container from a Resource. It is possible to perform this operation both from the Container and the Resource perspective.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Container exists, it is Active and Available.
  • The Container ResourceAssociationType must be DockedCarrier.
  • The Resource exists, it is Active and the property ResourceProcessingType is set to LoadPort.
  • The Container is currently associated with the Resource.

Sequence of Steps#

Step 1#

  1. Review the information.
  2. Optionally, enter a comment.
  3. If a State Model is defined for the Container, it is possible to change the state of the Container. If the selected state transition contains lookup reasons, it is necessary to select the Reason, as well.
  4. Press Undock to complete the operation.
