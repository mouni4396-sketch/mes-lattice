Remove Container from Container#

🔒 Container.RemoveContainer

Overview#

This operation is used to remove a Container from another Container.

As a naming convention, the Container that contains the Container is called Main Container and the Container to be contained is called Sub-Container.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Main Container is Active and Available.
  • The Position Unit Type of the Main Container is Containers.
  • The Sub-Container is Active and Available.

Preconditions for Bulk#

  • In addition to the preconditions mentioned above, all Containers must:
    • Be disassociated from the same Container.

Sequence of Steps#

Step 1: Details#

  1. Verify the Container information.
  2. Optionally, enter a comment.
  3. Select the Remove button to complete the operation.
