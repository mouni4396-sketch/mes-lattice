Empty Container#

🔒 Container.Empty

Overview#

This operation is used to empty a container i.e., to remove all current material associations with that container. The Materials are not to be selected individually for disassociation, i.e, when you click Empty, all the Materials will be removed from the Container.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Container is Active and it contains at least one Material.
  • If the Container position unit type is Material, there must be no Materials within the Container that are On Hold or In Transit.
  • If the Container position unit type is Container, there must be no Containers within the Container that is In Transit.

Sequence of Steps#

Step 1: Details#

  1. Review the Container and the Material information.
  2. Optionally, enter a comment.
  3. Select Empty to complete the operation.
