Release Send-Ahead Run Waiting Materials#

🔒 SendAheadRun.Extend

Overview#

This operation is used to manually release the Materials from a Send-Ahead Run with a positive outcome.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Send-Ahead Run exists in the system, the System State is Active and the state is Open.
  • All results from the Send-Ahead Run Materials are set to Pass.
  • The Auto Release on Pass property is set to false.

Sequence of Steps#

The Release Send-Ahead Run Materials wizard can be called from the Send-Ahead Run page within the Business Data Group, by selecting Release from the top ribbon.

Step 1#

  1. Review the original Send-Ahead Run information.
  2. Select Release to complete the operation.
