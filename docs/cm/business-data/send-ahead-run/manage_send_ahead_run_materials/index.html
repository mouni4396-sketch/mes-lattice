Manage Send-Ahead Run Materials#

🔒 SendAheadRun.Edit

Overview#

This operation is used to manage the Materials associated to a Send-Ahead Run.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • All Materials in the Send-Ahead Run Materials must be TopMost, Active and non-Template.
  • Every Material in the Send-Ahead Run Materials must be unique within the Send-Ahead Run.

Sequence of Steps#

Selecting a Send-Ahead Run that matches the preconditions, select Manage from the top ribbon.

Step 1: Waiting Materials#

  1. Add as many rows as desired (each row represents a new Material to be added to the Send-Ahead Run as a Waiting Material) by pressing in the top right of the grid and pressing to remove any added entry.

    Info

    The Material must be at or before the Send-Ahead Run Wait Step and it must be possible to reach the Evaluate Step and if defined, the Merge Step.

  2. General data will be displayed on the Material for which the Send-Ahead Run will be created. If the Material has Sub-Materials, you can also define some additional configurations:

    • Define the Split Type for the send-ahead scenario:
      • None
      • Logical
      • Physical
    • If the Split is defined as Logical or Physical, define the Split Scope. There are two options:
      • Temporary
      • Permanent
    • If the Split is defined as Logical or Physical, optionally define the default Container for the Sub-Materials.
  3. Select Next to continue to the next section.

Step 2: Sub-Materials to Send-Ahead#

Info

This step will only be displayed if any type of Split other than None was selected in the previous step and if the Materials don't have the Result set.

Select which of the Sub-Materials to be included in the Send-Ahead Run. At least one Sub-Material must be selected. After you select the Sub-Materials, select Next to continue to the next section.

Step 3: Send-Ahead Materials#

  1. Add as many rows as desired (each row represents a new Material to be added to the Send-Ahead Run as a send-ahead Material) by pressing in the top right of the grid and pressing to remove any added entry.

    Info

    The Material must be at or before the Send-Ahead Run Wait Step and it must be possible to reach the Wait Step, the Evaluate Step and if defined, the Merge Step.

  2. Information will be displayed for each of the Sub-Materials that will be included in the Send-Ahead Run.

  3. Select Update to complete the operation.
