Change Send-Ahead Run Materials#

🔒 SendAheadRun.Edit

Overview#

This operation is used to change Materials associated to the Send-Ahead Run from Waiting to Send-Ahead and vice-versa.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Send-Ahead Run exists in the system, the System State is Active and the state is Open.
  • To change a Waiting Material to a Send-Ahead Material:
    • The send-ahead Material must be at or before the Send-Ahead Run Evaluate Step and it must be possible to reach the Wait Step, the Evaluate Step and if defined, the Merge Step.
  • To change a send-ahead Material to a Waiting Material, the Material:
    • The send-ahead Material cannot have the result set to Pass.
    • The send-ahead Material must be at or before the Send-Ahead Run Wait Step and it must be possible to reach the Evaluate Step and if defined, the Merge Step.

Sequence of Steps#

The Change Send-Ahead Run Material wizard can be called from the Send-Ahead Run page within the Business Data Group.

Info

For this operation to be called directly from the Send-Ahead Run page, the Capture Results Mode must be set to Manual.

Waiting Materials to Send-Ahead Materials#

  1. Selecting a Send-Ahead Run that matches the preconditions, navigate to the Materials section and within that section open the Waiting Materials tab.
  2. Select a waiting Material by ticking the appropriate row.
  3. Select the Change button on top of the grid to open the wizard.
  4. Review the information Select Change to complete the operation.

Send-Ahead Materials to Waiting Materials#

  1. Selecting a Send-Ahead Run that matches the preconditions, navigate to the Materials section and within that section open the Send-Ahead Materials tab.
  2. Select a send-ahead Material by ticking the appropriate row.
  3. Select the Change button on top of the grid to open the wizard.
  4. Review the information Select Change to complete the operation.
