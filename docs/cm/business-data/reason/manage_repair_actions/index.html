Manage Repair Actions#

🔒 Reason.Edit

Overview#

This operation is used to Manage Repair Actions of a Reason.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Reason type is Defect.

Sequence of Steps#

The Manage Repair Actions wizard can be called from the Reason page within the Business Data Group.

Step 1#

  1. In the Reason page, select the Repair Actions section.
  2. Select Manage.

  3. Add, remove or update Repair Actions (use and on the top right of the grid), defining for each:

    • Repair Action name - must be unique within the Reason.
    • Description - optional.
    • Part Replacement Mode - Allowed, Not Allowed, Required.

  4. Select Update to complete the operation and the new Repair Action will be created.

Note

It is not possible to change the name of the Repair Action if it has been updated.
