Synchronize Scenario with Parent Plan#

🔒 Plan.Edit

Overview#

This operation is used to update the targets on the parent Plan of a Plan Scenario into this Plan Scenario. Depending on the value for the Sub Plan Volume Synchronization Mode property in the parent Plan, the following operations will be performed:

  • Breakdown Evenly By Period - for each of the time frames of the child Plan, the planned volume on the parent Plan will be set with the child plan quantity for that time frame.
  • Rule - the DEE Action associated with the defined Rule will be able to access all the planned volumes of the Plan Items and allow them to be changed by the action. See DEE Actions for more information on DEE Actions.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Plan exists in the system and is Active.
  • The Plan is a Plan Scenario and not an Effective Plan.
  • The Effective Plan of the Plan Scenario has a Parent Plan.
  • The Sub Plan Volume Synchronization Mode property of the Parent Plan is not set to None.

Sequence of Steps#

You can perform the Synchronize Scenario with Parent Plan operation from the Synchronize button located on the top ribbon of the Plan Scenario page.

Step 1: General Data#

  1. Confirm the information presented by the Wizard.
  2. Optionally enter a comment for the operation.
  3. Press Synchronize to complete the Wizard.
