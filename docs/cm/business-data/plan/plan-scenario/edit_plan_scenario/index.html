Edit Plan Scenario#

🔒 Plan.Edit

Overview#

This operation is used to manage the targets of an existing Plan Scenario.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Plan Scenario exists in the system and the System State is Active.

Sequence of Steps#

The Edit Plan Scenario can be called from the Plan Scenario page within the Business Data Group, under the Planning view.

Step 1: General Data#

Unlike the Edit Plan operation that allows editing the actual Plan, editing a Plan Scenario places the current Plan Scenario in an editing mode, allowing you to perform changes to the planned values defined for each of the time frames available. Selecting any of the grid cells will show a small popup dialog where you can enter the new target value for that time frame.

After editing the values, select Save on the top ribbon to complete the operation or Cancel to undo the changes.
