Plan Page#

🔒 SendAheadRun.Show

The Plan page displays general information on the specific Plan. It also gives you access to all available operations that can be performed on a specific Plan.

Details View#

Depending on the optional modules that are licensed in the system, the Details view will display some or all of the following page sections:

  • Details - displays general information on the Plan.
  • Items - displays the Plan Items that are associated with the Plan.
  • Volume Counting Steps - displays the Steps defined as counting for volume calculations in the Plan.
  • Excluded Material Types - displays the Material types that are excluded from volume calculations in the Plan.
  • Plan Scenarios - displays the Plan Scenarios that are associated with the Plan.
  • Plan Groups - set of Plans with the same manufacturing level, time unit and plan item level, which reference different manufacturing units and that are meant to be solved or analyzed at the same time.
  • Sub-Plans - displays Plans that are children of the current Plan.
  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information on Attributes, visit the section Attributes.
  • Attachments - shows the documents that are attached to the Plan and enables the user to attach additional documentation to the Plan.

Planning View#

This view provides a planning grid that allows you to set targets for each of the time frames previously defined when creating the Plan and to have a global view of the Plan progress.

You can filter the matrix view by using the available filters:

  • Show Closed - allows you to only see the Plan Items that have state Closed.
  • View Mode - allows you to decide to display the volume quantity or a percentage of actual vs planned volume.
  • Product/Product Group - allows you to see only the Plan Items of a specific type, depending on what was specified then the Plan was created.
  • From Date - allows setting the beginning of a temporal window of visualization.
  • To Date - allows setting the end of a temporal window of visualization.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Plan and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Plan and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Plan object:

  • History - displays the history of the operations, associated information, the user who performed the changes and when the changes happened.
