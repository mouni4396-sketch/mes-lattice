Maintenance Plan Instance Page#

🔒 MaintenancePlanInstance.Show

Overview#

The Maintenance Plan Instance page displays all the operations that can be performed within a specific Maintenance Plan Instance. Additionally, it displays the Details of the Maintenance Plan Instance, as illustrated below.

Details View#

The Details view will display some or all of the following page sections:

  • Details - displays general information on the Maintenance Plan Instance.
  • Attachments - shows the documents that are attached to the Maintenance Plan Instance and enables the user to attach additional documentation to the Maintenance Plan Instance.

Scheduler View#

The Scheduler view displays a calendar with information on the Maintenance Activities that are a part of the current Maintenance Plan Instance.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Maintenance Plan Instance and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Maintenance Plan Instance and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Maintenance Plan Instance object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
