Copy Data Collection Limit Sets#

🔒 DataCollectionLimitSet.Create

Overview#

This operation copies Data Collection Limit Sets from other Data Collections.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • Data Collection version is Active or Effective.

Sequence of Steps#

This operation can be performed by selecting the Copy button in the Limit Set section of the Data Collection entity page that has the source Data Collection Limit Sets that you want to copy. If the operation is called from the Data Collection wizard, the selection is automatic.

Step 1: Change Set#

  1. Select an existing Change Set or select Create New to create a new Change Set to be used for this purpose. If the support of Implicit Change Sets has been configured beforehand, it is also possible to check the option Use Automatic Change Set.
  2. Optionally, select an Approver Role.

Step 2: Limit Sets#

  1. Select the Data Collection Limit Sets to be copied by checking them from the list. Optionally, you can filter by displaying all Limit Sets from a specific Data Collection or by actual specific Data Collection Limit Sets.

Step 3: Limit Sets Names#

  1. Because Data Collection Limit Sets cannot have duplicate names, the system will automatically add the name of the current Data Collection together with an underscore ('_') as a prefix. It is possible however to edit the name
  2. Select the Copy button to complete the transaction.
