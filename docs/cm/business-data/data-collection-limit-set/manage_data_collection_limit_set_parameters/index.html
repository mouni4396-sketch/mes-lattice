Manage Data Collection Limit Set Parameters#

🔒 DataCollectionLimitSet.Edit

Overview#

This operation is used to Manage Data Collection Limit Set Parameters.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Data Collection Limit Set exists in the system and is in Created state.

Sequence of Steps#

The Manage Data Collection Limit Set Parameters wizard can be called from the Data Collection Limit Set page within the Business Data Group.

Step 1: Parameters#

  1. Select Manage in the Parameter Limits section.
  2. Add, remove or edit Parameters as needed (use and on the top right of the grid).
  3. Optionally, enter a comment.
  4. Select Next.

Note

The following optional features are also available on this screen:

Synchronize - this option will enable the synchronization (by removing excessive parameters and adding the missing ones) between the Data Collection Limit Set parameters and the Data Collection parameters.

Copy - this allows you to copy the parameters from an existing Data Collection Limit Set by selecting the Copy button to later apply them to another Data Collection.

Step 2: Samples#

  1. If Include Sample Limits is set to True, you can add, remove or edit Sample Limits for the Parameter in this tab (use and on the top right of the grid).
  2. Optionally, enter a comment.
  3. Select Update to complete the operation.
