Clone Substrate Map Mask#

🔒 SubstrateMapMask.Clone

Overview#

This operation is used to clone an existing Substrate Map Mask into a new Substrate Map Mask with a different name and identical characteristics.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Substrate Map Mask exists in the system.

Sequence of Steps#

The Clone Substrate Map Mask wizard can be called from the Substrate Map Mask page within the Business Data Group. The default values will be taken from the current Substrate Map Mask to be used as a base for the new object.

Step 1: General Data#

  1. On the left side panel, add the rows you need (each row represents a new Substrate Map Mask to be created based on the currently selected Substrate Map Mask) by selecting . You can also specify the Number of clones by using the drop-down option:

  2. Specify the property values for each new instance you create. You can also provide a Name for each of the new instances, however if a Name Generator is configured for the Entity Type, you can leave the field blank and a new name will be automatically generated.

  3. Enter the Description.
  4. Enter a comment for the operation.

  5. Select Clone to complete the operation and a new object will be created.

Info

For more information on these and other features of cloning, see Cloning an Object.
