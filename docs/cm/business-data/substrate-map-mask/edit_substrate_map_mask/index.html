Edit Substrate Map Mask#

🔒 SubstrateMapMask.Edit

Overview#

This operation is used to edit a Substrate Map Mask object.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Mapping module (if part of CM MES) or App license (if part of an Application) must be properly licensed.
  • The Substrate Map Mask must be Active.

Sequence of Steps#

Edit Substrate Map Mask From a Substrate Map Mask#

Step 1: General Data#

  1. In the chosen Substrate Map Mask, select Edit Content on the top ribbon:

  2. Use the Add Units (default) and Remove Units buttons on the right to include or exclude units from the mask:

    Info

    The Add Units sets the SetValue to the selected unit, and Remove Unit sets the EmptyValue to the selected unit.

  3. Select Save to complete the operation and save changes permanently:
