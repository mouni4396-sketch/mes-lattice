Complete Transfer Order Movement#

🔒 TransferOrder.CompleteMovement

Overview#

This operation is used to complete the movement of a Transfer Order.

Setup#

No special setup is required other than to meet the preconditions.

Preconditions#

  • The Transfer Order must be active and system state must be In Progress.
  • If there is an Owner defined for the Transfer Order, the current Employee must match that Owner.

Sequence of Steps#

Step 1#

  1. Review the Transfer Order items information.
  2. If a Resource is set, select the new system state for the Transport Resource.
  3. If the automatic confirmation was not set, select whether the items should be confirmed.
  4. Press the Complete button to complete the operation.
