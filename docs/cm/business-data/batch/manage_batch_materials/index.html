Manage Batch Materials#

🔒 Batch.ManageMaterials

Overview#

This operation is used to Manage Batch Materials.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Batch exists in the system and is Active.
  • The Batch System State is Created.
  • All Materials must be top-level Materials, Active, non-templates, and have the same Primary Units.
  • If the Batch Material Split Mode is set to NotAllowed, the Batch Material Quantity must equal the total of the Material Primary Quantity plus the Sub-Materials Primary Quantity - meaning the material cannot be split.

Sequence of Steps#

  1. Choose Batch, then select the Manage Batch Materials button in the Materials Section.

  2. For each Batch Material, you can update:

    • Material.
    • Main Material, using the toggle button Set as Main Material.
    • Step, for any Material except the Main Material.

    Warning

    For any Material that is not Set as Main Material, you can select a different Step from the Batch Step, as long as the Required Service of the selected Step is either available on the Batch Resource or is a Compatible Service of one of the Resource available Services. For more information, see Manage Compatible Services.

    To align the selected Material with the Batch Step, you can also use the Apply Batch Step button.

    The Batch Materials can only be updated when the Batch is in the Created state. For more information, see Batch System States. If you want to remove the Main Material of the Batch, you must first set another Material as Main.

  3. Optionally, enter a comment for the operation.

  4. Select Update.
