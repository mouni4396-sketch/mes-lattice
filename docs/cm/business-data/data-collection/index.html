Data Collection#

🔒 DataCollection.Show

Overview#

A Data Collection refers to a plan to collect quantitative and qualitative data at ad-hoc or specific processing points. It consists of a set of qualified Parameters associated to the Data Collection that specify the sample material form (batch, lot, wafer), number of samples, number of readings per sample, whether the parameter is mandatory or not, the parameter calculation (if any), and how limits are checked.

Limit checking is controlled at two levels:

  • Data Collection: defines when warning and error limits are evaluated for long-running instances.
  • Data Collection Parameter: defines whether limits are checked against each individual value or against the calculated value.

The Data Collection version can evaluate warning and error limits as follows:

  • On Post: limits are checked whenever data is posted.
  • On Close: limits are checked only when the Data Collection Instance is closed.

At parameter level, limits can be evaluated as follows:

  • Individual Value: limits are checked against individual values.
  • Calculated Value: limits are checked against the calculated value defined by the parameter calculation and CalculationGroupingMode. This is only available when CalculationGroupingMode is different from None.

Data Collections will be used to create Data Collection Instances. A Data Collection Instance can be:

  • Immediate - all the data is collected at one time according to a pre-defined Data Collection.
  • Immediate Ad-hoc - all the data is collected at one time and without any pre-defined Data Collection.
  • Long Running - the data is collected according to a pre-defined Data Collection and at different points in time, usually over a long period of time. The Data Collection Instance needs to be opened and closed.

Data Collections can be used stand-alone or integrated with Material Tracking, Resource Tracking, and Maintenance Management.

Sequence Of Steps#

The necessary steps for correctly using a Data Collection are the following:

  1. Create all the Parameters required by the Data Collection.
  2. Create a Data Collection - the Data Collection Version must be associated with a Change Set.
  3. Approve the Change Set, which contains the Data Collection that was created.
  4. Optionally, create Data Collection Limit Sets for the Data Collection.
  5. Decide whether limit checking for long-running instances should happen on each post or only on close.

Info

For convenience, the Data Collection can be configured to use implicit Change Sets.

For more information, see the Data Collection tutorial.
