Open Data Collection Instance#

🔒 DataCollectionInstance.Open

Overview#

This operation is used to create and open a long-running Data Collection Instance. Data can be posted multiple times until the Data Collection Instance is closed.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Data Collection Version is Effective.

Sequence of Steps#

  1. Optionally, enter the name of the Data Collection Instance - otherwise, an automatic name will be provided by a name generator.
  2. Optionally, enter the description of the Data Collection Instance.
  3. Optionally, select a Data Collection Limit Set.

  4. Optionally, select a Material to be associated with the Data Collection.

    Warning

    Some Data Collections can require a mandatory Material/Sub-Materials of a certain Form, defined in the Data Collection Parameter's settings for Sample Type, Source and Percentage. A Material will also be mandatory if the Limit Set contains a Relative parameter limit, as the value is relative to the primary quantity of the Materials.

  5. Optionally, enter a comment.

  6. Select Open to complete the transaction.

Info

The Data Collection parameters may have validation ranges that have to be followed in order for the values to be accepted.

Info

A Data Collection may be configured to send data to SPC, in which case one or more SPC Charts will appear.
