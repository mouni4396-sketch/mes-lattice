Download Map Layer Information#

🔒 Material.Show

Overview#

This operation is used to export Map Layer information content to a downloadable file.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Map and the Material both exist and are Active.
  • The Map has information associated to a Map Layer.

Sequence of Steps#

  1. Select the appropriate Map and navigate to the Layers section in the Map details view.
  2. Select the desired layer from the grid.
  3. To download the layer information, select the button on top of the grid. The file will be downloaded to the default location specified in the browser settings and it will include the information for the layer, including X position, Y position and other layer unit data information.
