Link Map with Material#

🔒 Material.LinkWithMap

Overview#

This operation is used to link a Map with a Material. It can be done both from the Map and the Material perspectives.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Map and the Material exist and are Active.
  • The Map is not yet associated with any Material.
  • There can only be one Map marked as Master for a given Material, and there must be, at least, one.

Sequence of Steps#

From the Map perspective#

  1. Select the Map to which you wish to link the Material.
  2. In case it is not the first Map that is being associated to the Material, the user will be able to determine the Map order.
  3. If the Map is set as a Master Map, the Linkage Mode will have to be defined (only applicable if the Map Definition of the Map contains units matching the Material primary or secondary units and if the Map Definition default layer is of type Loss or Bin):
    • Verify - checks whether the Material quantity (of the matching units) equals the good units of the Map being linked; the link will fail if the quantities are different.
    • Synchronize - sets the Material quantity (the matching units) with the quantity of good units of the Map being linked.

  4. Choose if the Map is default or not (only if the Material does not currently have a Map whose IsMerged property is set to true) and if the Map is merged. To activate the Merged Map flag, the following conditions must be met:

    • The Material does not have a Map with IsMerged property set to true.
    • The Map is set as default.
    • The Map default layer is Loss.
    • The Map Material Units must match the Material primary or secondary units.

  5. Optionally, enter a comment.

  6. Press Link to complete the transaction.

From the Material perspective#

  1. On the Maps tab, click Manage and click on the + (plus) button to add a Map.
  2. Under Map Details you will be able to define if the Map shall be a Master Map or a Merged Map by setting the respective button to true.
  3. If the Map is set as a Master Map, the Linkage Mode will have to be defined (only applicable if the Map Definition of the Map contains units matching the Material primary or secondary units and if the Map Definition default layer is of type Loss or Bin):
    • Verify - checks whether the Material quantity (of the matching units) equals the good units of the Map being linked; the link will fail if the quantities are different.
    • Synchronize - sets the Material quantity (the matching units) with the quantity of good units of the Map being linked.
  4. Optionally, enter a comment.
  5. Press Link to complete the wizard.
