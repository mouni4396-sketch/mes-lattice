Service Page#

🔒 Service.Show

The Service page displays general information on the specific Service. In addition it enables the user to perform all the operations that can be performed on a specific Service.

Details View#

Depending on the optional modules that are licensed in the system, the Details view will display some or all of the following page sections:

  • Details - displays general information on the Service.
  • Resources - displays which Resources are currently providing the Service.

  • Compatible Services

    • Can be Fulfilled by - displays which Services can replace the current Service (both Services exist either as Source or Target entity in a Relation).
    • Can Fulfill - displays which Services the current Service can replace if needed.

  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information on Attributes, visit the section Attributes.

  • Attachments - shows the documents that are attached to the Service and enables the user to attach additional documentation to the Service.

Contexts View#

This view shows information concerning all the contexts currently connecting the Service to other objects in the system:

  • Recipe Context - displays the existing Relations between the Service and Recipe that have been manually created in the system.
  • Service Context - displays the existing Relations between the Service and the optional Material, Flow and Product combinations.

Info

Note: Combinations are managed in a Smart Table and are not added manually in this panel. More information in the ServiceContext page.

Note

To be able to edit the data contained in the Context tables, you will need the ContextResolution.EditData security feature.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Service and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Service and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Service object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
