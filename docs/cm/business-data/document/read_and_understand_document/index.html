Read and Understand Document#

🔒 Document.ReadAndUnderstand

🔒 Document.Show

Overview#

This operation stores the acknowledgement from the Employee that they read and understood a particular document version.

Note

By design, the Read and Understand option only appears for new document revisions, as new versions are considered minor changes (interchangeable), and without influence on the final result.

Setup#

There is a system configuration (/Cmf/System/Configuration/DocumentManagement/ReadAndUnderstandValidation) that controls the system behavior in case you have not acknowledged the reading and understanding of a specific Document at specific transactions during the normal operation. These possible states are:

  • None (default) - you can proceed without reading and understanding.
  • Warning - you can proceed without reading and understanding but a warning is shown.
  • Error - you cannot proceed without reading and understanding.

Preconditions#

  • Employee has not yet performed the Read and Understand for this particular document version.
  • The Document version must be Active or Effective.
  • The Employee belongs (directly or indirectly) to one of the applicable Roles configured for the Document.

Warning

A number of specific applicable Roles should be defined for each Document in order to establish who has the right permissions to access the object. These roles must be edited in the main Document page.

Sequence of Steps#

  1. Select Read and Understand on the top ribbon.
  2. Read the Document.
  3. Select the Read and Understood option.
  4. Select Read and Understood to close the window.

Warning

If the Document is set to require a signature for reading and understanding, and an expiration time (in days) exists, any signature will expire after that specific period elapses, and it will need to be signed again.
