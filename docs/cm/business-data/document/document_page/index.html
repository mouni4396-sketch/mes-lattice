Document Page#

🔒 Document.Show

The Document page displays general information on the specific Document. In addition, it enables you to perform all the operations that can be performed on a specific Document.

Details View#

Depending on the optional modules that are licensed in the system, the Details view will display some or all of the following page sections:

  • Details - displays general information on the Document.
  • Applicable Roles - displays the Roles that are applicable for reading and understanding a specific Document.
  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information, see Attributes.
  • Attachments - shows the documents that are attached to the Document and enables you to attach additional documentation to the Document.

Tracking View#

This view shows information on the Employees that have read and understood the document.

Contexts View#

This view shows information concerning all the contexts currently connecting the Document to other objects in the system:

  • Material Context - displays the existing Relations between the Document and Materials that have been created in the system.
  • Resource Context - displays the existing Relations between the Document and Resources that have been created in the system.

Note

To be able to edit the data contained in the Context tables, you will need the ContextResolution.EditData security feature.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Document and other entities and enables the user to edit them. For more information, see Relations.
  • Where Used - displays the set of relationships between the Document and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Document object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
