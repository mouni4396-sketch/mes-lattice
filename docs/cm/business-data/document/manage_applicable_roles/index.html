Manage Applicable Roles#

🔒 Document.Edit

Overview#

This operation is used to manage roles applicable to the Document.

Applicable Roles specify which users are required to complete Read and Understand for the Document. Only users assigned to these roles will see the Document listed for acknowledgment.

Note

Applicable Roles do not grant permissions to manage the document — these are assigned exclusively to the Owner Role.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Document Management module is properly licensed in the system.
  • If the Document has an Owner Role defined, you must belong to that current Owner Role.

Sequence of Steps#

Step 1#

  1. Select an appropriate Document, navigate to the Applicable Roles section and press the Manage button.
  2. Add as many Roles as desired (select in the top right of the grid to add and to remove) to which this Document will apply.
  3. Select Update to complete the operation.

Note

You must configure the system for each operation to ensure you have read and understood the Document before proceeding.

To do this, navigate to Configuration. Under the path /Cmf/System/Configuration/DocumentManagement/ReadAndUnderstandValidation/, enable each operation you want the system to enforce Read and Understand. For more information, see System Configuration Entries.
