Manage Product Component Information#

🔒 Product.Edit

Overview#

This operation is used to manage Product Components, specifically the mapping to the Product.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • Product exists in the system and it is not a Template.
  • The State of the Product is Created.
  • The Product has at least one component.

Sequence of Steps#

The Manage Product Components Information wizard can be called from the Product page by selecting Components from the section menus on the right, and then selecting the Manage tab.

Step 1: General#

  1. On the Components panel, use the ellipsis dropdown to manage Components by performing the following actions globally to every listed component:

    • Clear all component values.

    • Apply component mapping automatically to all.

      Note

      This action will clear any component property value that was previously set.

  2. You can also manage Components by performing the following actions individually to every listed component:

    • Clear the current Product value.
    • Set a new Product value.
    • Apply component mapping for an individual component.

  3. Optionally, enter a comment.

  4. Select Update to complete the operation.
