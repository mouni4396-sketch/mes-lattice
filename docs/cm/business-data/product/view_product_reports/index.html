View Product Reports#

🔒 Product.ViewReports.StandardCost

🔒 Product.ViewReports.StandardFlow

Overview#

This operation is used to generate and visualize reports on Product cost and flow.

Setup#

No setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • Product exists and it is Active in the system.

Note

For the user to have access to the reports tree, permission must be granted in the report server. For more information, see Report Folders.

Sequence of Steps#

  1. Select a Product and click on View Reports.
  2. You will be given the option to select different reports on the specific Product, namely:
    • Cost Report (for more information, see Product Standard Cost Report)
    • Flow Report (more information, see Product Standard Flow Report)
  3. Select one of the options, fill in the blank fields with the required information and set the buttons to true or false according to your preferences.
  4. The system will generate the report. If you wish to save it, you can do so by clicking on the Export icon which will enable you to export and save the report in different formats.

Info

For more information, see Analytics Views.
