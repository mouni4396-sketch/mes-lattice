Product Standard Flow Report#

🔒 Product.ViewReports.StandardFlow

Description#

This report provides access to the Product Standard Flow report of any Product which is available in the Operational Data Store (ODS) database.

Data Source(s)#

  • ODS database

Filters#

You can customized the Standard Flow report by selecting the options below:

  • BOM
  • Checklist
  • Data Collection
  • Document
  • Durables
  • Future Action
  • Inspection Plan
  • Line Flows
  • Personnel Requirements
  • Recipe
  • Resource
  • Reworks
  • Sampling
  • SPC
  • Time Constraints

To select these options, simply choose the True radio button, as shown below.

Note

The information regarding the Line Flows and the Reworks associated with the Product will appear at the end of the report.

Fields#

  • Product
  • Flow
  • Flow Structure
