Manage Characteristics#

🔒 Product.Edit

Overview#

This operation is used to manage the Characteristics of the Product.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • Product exists in the system and it is Active.

Sequence of Steps#

The Manage Characteristics wizard can be called from the Product page by selecting Characteristics and Rules from the section menus on the right, and then selecting the Characteristics tab.

Step 1: General#

  1. Manage the settings and specify if the product is Configurable.

    Note

    The default value is false. If configured to true, you must specify at least one Product Characteristic.

  2. Select Next to continue.

Step 2: Characteristics#

  1. Specify as many characteristics as you need by using .

  2. Specify the Characteristic Details by providing the following information:

    • Characteristic - the unique name of the characteristic.
    • Description - the description of the characteristic.
    • Optional - whether the characteristic is optional. Defaults to false, which means that the characteristic is mandatory.

    • Source - defines where the Product Characteristic comes from. This field is mandatory and must be either:

      • Default Value - enter manually a user-defined value

      • Value Table - select the name of a valid and active Source Lookup Table with the predefined values.
      • Default Value - choose a predefined value from the specified Source Lookup Table.

      Note

      For more information, see How to: Create a Lookup Table.

    Note

    By default, the Source field is hidden in the table view. To reveal it, select the icon in the top-right corner of the characteristics table and enable the Source column.

  3. Select Update to complete the operation.
