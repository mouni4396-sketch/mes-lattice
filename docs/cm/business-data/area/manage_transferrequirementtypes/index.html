Manage Transfer Requirement Types#

🔒 Area.Edit

Overview#

This operation is used to manage the Transfer Requirement Types for an existing Area.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Area exists in the system.
  • The Area is of AreaType StorageArea.

Sequence of Steps#

The Manage Transfer Requirement Types wizard can be called from the Area page within the Business Data Group, scrolling to the Transfer Requirement Types section in the main Area page. In the wizard:

  1. On the left side panel, add as many rows as desired (each row represents a new Transfer Requirement Type to be added to the currently selected Area) by pressing in the top right of the grid and pressing to remove any added entry.
  2. Select the Type for the new Transfer Requirement. The list of possible values is taken from the lookup table TransferRequirementType.
  3. Select the Source Location to use for the Transfer Requirement. The values are retrieved from the list of Areas used as Supply Areas. More information on Manage Supply Areas.
  4. If the Area is of type Production Line, select a Destination Location.
  5. Choose whether to automatically approve the Transfer Requirement.
  6. Choose whether to enable Partial Release.
  7. Choose whether to automatically release the Transfer Requirement.
  8. Choose whether to create a separate list for Floor Life definition. If you decide to create a separate pick list, the Materials selected must have the property Floor Life Remaining Time with a value different from null.

  9. Choose whether to create a separate list for each Storage Resource in the Area, allowing improved distribution of the workload based on distance or other route optimization strategy.

    Info

    If both options are set as true, separate Pick Lists will be created for each distinct combination of Storage Resource and Floor Life Material value.

  10. Choose whether to skip the picking step of the Transfer Requirement.

  11. Choose whether to enable automatic picking of the Transfer Requirement.
  12. Choose whether to enable Partial Delivery.
  13. Select if the Transfer Requirement will delivered automatically after picking.
  14. Choose whether to enable automatic confirmation of the Transfer Requirement.
  15. Press Update to complete the transaction.
