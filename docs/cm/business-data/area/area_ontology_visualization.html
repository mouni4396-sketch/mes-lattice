Ontology Extraction Methodology

This method defines a systematic structure to ingest documentation guides from the Critical Manufacturing MES and automatically generate formal, semantic RDF/OWL ontology graphs.

01

Class & Subclass Ingestion

Scan overview sentences to extract semantic structures. Direct definitions ("An X is a logical grouping of Y") identify class instances. Sub-options ("Area types: Production Line, Storage Area") establish hierarchical subClassOf taxonomy relationships.

02

Object Property & Link Extraction

Map page sections and details components (e.g., Steps, Resources, Sub-Areas) as OWL Object Properties linking classes. For instance, mapping the "Steps" section from the Details View directly to a groupsStep object property connecting class:Area with class:Step.

03

Data Property Classification

Ingest wizard sequence fields (Name, Description, Cost Center, Distribution List) to define OWL Data Properties. These represent attributes belonging to classes, mapped to XML Schema datatypes (string, integer, boolean).

04

Transactional Operation Ingestion

Ingest operation pages as system Transactions (subclasses of class:Operation). For each operation, parse security permissions (🔒), state preconditions, and setup variables, linking them back to target classes via hasTargetClass or modifies properties.
