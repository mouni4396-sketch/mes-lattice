Area Page#

🔒 Area.Show

The Area page displays general information on the specific Area. In addition it enables you to perform all the operations that can be performed on a specific Area.

Details View#

Depending on the optional modules that are licensed in the system, the Details View will display some or all of the following page sections:

  • Details - displays general information on the Area.
  • Steps - displays the list of Steps that belong to a specific Area.
  • Resources - displays the list of Resources that belong to a specific Area.
  • Sub-Areas - displays the Sub-Areas defined for the Area.
  • Supply Areas - displays the Supply Areas defined for the Area (only if the Area Type property is set to Production Line or Storage Area).
  • Transfer Requirement Types - displays the Transfer Requirement Types defined for the Area (only if the Area Type property is set to Production Line or Storage Area).
  • Shift Logbooks - displays the Shift Logbooks associated to the Area. Only displayed if Shift Logbooks are enabled for the Area.
  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information on Attributes, see Attributes.
  • Attachments - shows the documents that are attached to the Area and enables you to attach additional documentation to the Area.

Info

The Details View will change according to the Area Type, showing different information pertinent to the type of Area currently being viewed. For Areas such as the ones with types Production Line or Storage Area, more detailed information on Picking and Flow Path is shown.

Area View#

This view shows information on all the Steps and Resources that are contained in the Area. It serves as a link to the FabExplorer page of the same Area.

Maintenance View#

This view shows you all of the Maintenance Activities planned for the Area.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing relations between the Area and other entities and enables you to edit them. For more information, see Relations.
  • Where Used - displays the set of relationships between the Area and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Area object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
