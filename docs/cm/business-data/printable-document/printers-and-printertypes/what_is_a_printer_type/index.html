What is a Printer Type#

A Printer Type is a classification meant to configure printers in which a Printable Document can be printed (e.g. due to the nature of the document, available paper type, etc).

Each printer can be part of multiple Printer Types.

Note that during the printing of multiple Printable Documents, only those with the same Printer Type can be printed simultaneously, since the user is offered the possibility to select a single printer where all documents will be printed.
