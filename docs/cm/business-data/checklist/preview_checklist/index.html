Preview Checklist#

🔒 Checklist.Preview

Overview#

This operation is used to Preview a Checklist.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Checklist exists in the system and is not Terminated.
  • The Checklist scope is Material Tracking or Maintenance Management.

Sequence of Steps#

The Preview Checklist wizard can be called from the Checklist page within the Business Data Group.

Checklist Without Conditions#

This feature lets you preview how the Checklist will appear when performed under typical conditions. To preview a Checklist without any conditions, simply select the Preview button on the top ribbon to view the complete Checklist as it would be performed.

Checklist With Conditions#

For Checklist items containing specific conditions:

  • If the Checklist includes items with conditions based on a Date Interval, you’ll need to specify a date to simulate the scheduled date for the Checklist to be performed.

  • For Checklist items with BOM Item or Expression conditions, you can select either a Material or Product.

    • If a Product is defined for the Checklist, you can only choose a Material associated with that Product. In this case, the selected Material must include the necessary characteristics, with values provided either by selecting from the associated Lookup Table or by entering free text.
    • Alternatively, you can select a Product, which can be either the Checklist specified Product or any Product with the defined characteristics. In this case, it will simulate the values of the Product characteristics as required, also using either Lookup Table entries or free text.
    • If the expression configured in the condition references any Step properties, you must also fill in the Step information.

  • Once you set the context, the system will apply the filters and display the Checklist with the filtered and active items, giving you a clear view of which items will be performed.
