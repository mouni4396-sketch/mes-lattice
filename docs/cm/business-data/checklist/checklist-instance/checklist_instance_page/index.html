Checklist Instance Page#

🔒 ChecklistInstance.Show

The Checklist Instance page displays general information on the specific Checklist Instance. In addition it enables you to perform all the operations that can be performed on a specific Checklist Instance.

Details View#

Depending on the optional modules that are licensed in the system, the Details view will display some or all of the following page sections:

  • Details - displays general information on the Checklist Instance, including the context for the Checklist Instance.
  • Deviations - displays information on Deviations Open For Material, which will be approved or rejected. For more information, see Close Protocol Instance.
  • Attributes - enables the visualization of existing Attributes and the possibility to create new ones. For more information on Attributes, visit the section Attributes.
  • Attachments - shows the documents that are attached to the Checklist Instance and enables you to attach additional documentation to the Checklist Instance.

Note

If the scope of your Checklist is Material Tracking, the Checklist Instance will include Material information.
Additionally, there will be a section on Deviations if these have been opened. For more information, see Open Material Deviation and Close Protocol Instance.

Checklist Items View#

Displays general information on the items that compose the Checklist (example contains deviations). For more information, see Perform Checklist Instance.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Checklist Instance and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Checklist Instance and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Checklist Instance object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
