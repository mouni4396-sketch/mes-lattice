Create Shift Definition#

🔒 ShiftDefinition.Create

🔒 ShiftDefinition.CreateTemplate

🔒 ShiftDefinition.CreateFromTemplate

Overview#

This operation is used to create a Shift Definition. A template can also be created using a similar procedure and there is also the possibility of using a template to create the new object as well. This selection can be done in the main entity menu.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Shift Definition does not currently exist in the system.

Sequence of Steps#

Step 1: General Data#

  1. Provide a name for the Shift Definition.
  2. Optionally, provide a description of the Shift Definition.

  3. Select the Calendar on which the Shift Definition is based.

    Info

    A Shift Definition can only be added to a Calendar Day if it has the same start time as the Calendar Day.

  4. Select Next to continue to the Shifts configuration of the Shift Definition.

Step 2: Shifts#

This section is used to define the shifts of the Shift Definition. Add as many shifts as desired (press in the top right of the grid to add, and to remove), specifying for each shift:

  1. Provide a Shift Name

  2. Specify the Shift Start Time and the Shift End Time

    Info

    The first Shift must start in the Shift Definition start time (inclusive) and the last Shift must end in the Shift Definition start time as well (exclusive).

  3. Optionally, specify the shift code (used for Shift Planning purposes).

  4. Specify the cost overtime factor (defaults to one, which means no overtime).
  5. Optionally, define a Team pattern as a sequence of Team codes from Teams of the same Calendar as the Shift Definition. Note that all Team patterns for all Shift Definition Shifts must have the same length.
  6. Optionally, define the foreground and background colors for the Shift (used for Shift Planning purposes).
  7. Select Next to continue to the Non-working times configuration of the Shift Definition.

Step 3: Non-working times#

This section is used to define the non-working times for each of the shifts of the Shift Definition. Add as many non-working times as desired (press in the top right of the grid to add, and to remove), specifying for each non-working time of each shift:

  1. Name
  2. Start time (must fall within the shift start and end time)
  3. End time (must fall within the shift start and end time)
  4. Select Create to complete the operation and the new Shift Definition will be created.
