Manage Shift Definition Shifts#

🔒 ShiftDefinition.Edit

Overview#

This operation is used to Manage Shifts of a Shift Definition.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Shift Definition exists in the system.

Sequence of Steps#

The Manage Shift Definition Shifts wizard can be called from the Shift Definition page within the Business Data Group.

Step 1: Shifts#

  1. Select the Shifts section in the Shift Definition page.
  2. Select Manage to call the Manage Shift Definition Shifts wizard.
  3. Add as many entries as you need (select in the top right of the grid to add and to remove) and provide the following information for each shift:
    • Name
    • Start Time
    • End Time
    • Code
    • Cost Overtime Factor
    • Team Pattern
    • Background Color
    • Foreground Color
  4. Optionally, enter a comment.

Step 2: Non-Working Times#

  1. Select the Shift you want to edit.
  2. Add as many entries as you need (select in the top right of the grid to add and to remove) and provide the following information for each non-working time:
    • Name
    • Start Time
    • End Time
  3. Optionally, enter a comment.
  4. Select Update to complete the operation.
