Employee Page#

🔒 Employee.Show

The Employee page displays general information on the specific Employee. In addition it enables the user to perform all the operations that can be performed on a specific Employee.

Details View#

Depending on the optional modules that are licensed in the system, the Details view will display some or all of the following page sections:

  • Details - displays general information on the Employee.
  • Subordinates - displays information on the other Employee(s) that are currently assigned to the Employee as subordinates.
  • Delegates - displays information on the other Employee(s) that are currently assigned to the Employee as delegates.
  • Certifications - displays information on the Certifications that the Employee holds.
  • Qualifications - displays information on the Qualifications that the Employee holds.
  • Time Sheet Entries - displays information on the entries in the time sheets concerning this Employee.
  • Check-In Info - displays information on the events registered when the Employee checks-in to an entity in the system.
  • Attachments - shows the documents that are attached to the Employee and enables the user to attach additional documentation to the Employee.

Calendar View#

Displays visual information and allows specific configuration on the calendar days generated for the Employee.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Employee and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Employee and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Employee object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
