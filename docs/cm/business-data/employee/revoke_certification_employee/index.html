Revoke Certification from Employee#

🔒 Certification.Revoke

Overview#

This operation revokes a specific Certification from one or more Employees, causing the Employees to no longer hold the Certification. The Employee will remain assigned to the Certification.

Preconditions#

  • The user must belong to the Owner Role of the Certification.
  • The users being revoked must currently have the property Certification Date set (note that it can be logically Certified or Expired).
  • The Certification must have the property Grant Type set to Manual.

Sequence of Steps#

To revoke one or more Certifications from a specific Employee, open the page of the Employee, navigate to the Certifications section of the page, select the Certification to be revoked, and select the Revoke button.

Step 1: Details#

  1. Confirm the Certification to be revoked from the Employee.
  2. Optionally enter a comment for the revoke.
  3. Select Revoke to complete the operation.

Info

If the Certification has the property Notify users that should obtain this Certification set to true, an individual email will be sent to them.
