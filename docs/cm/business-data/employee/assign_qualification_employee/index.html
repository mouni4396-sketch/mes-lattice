Assign Qualification to Employee#

🔒 Qualification.AssignEmployees

Overview#

This operation assigns Qualifications to the selected Employee.

Preconditions#

  • The Employees are Active and do not currently have another manager assigned.
  • Employee is Manager of the Employee in the Employee Qualification and the Qualification has the property IsManagerAssignAllowed* set to true.
  • Current user is the same Employee in the Qualification.
  • The Qualification has the property IsSelfAssignAllowed set to true.

Sequence of Steps#

To assign one or more Qualifications to a specific Employee, open the page of the Employee, navigate to the Qualifications section of the page and select the Assign button.

Step 1: Details#

  1. Select the Qualifications(s) that should be assigned by using the button or remove them by using the button.
  2. It's necessary to define the proficiency and the reason for the Qualification. The default reason will be taken automatically if it's defined.
  3. If there is a validity defined, it will be set automatically. If the Qualification allows the validity to be overridden, the user may override it.
  4. Optionally, enter a remark for the assignment.
  5. Optionally, enter the evidence for the Qualification achievement.
  6. Select Assign to complete the operation.

Note

Duplicated Employee Qualification records can exist for the same Qualification – with the same or different Proficiencies. When this happens, only the most recent Qualification is considered in the business logic.
