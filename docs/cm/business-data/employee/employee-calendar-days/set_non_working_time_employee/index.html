Set Employee Non-Working Time#

Overview#

This operation allows the definition of non-working time for a given Employee.

Preconditions#

For the selected Employee Calendar Days:

  • IsCalendarWorkingDay is true
  • There cannot be overlaps - note that the start times are inclusive and end times are exclusive
  • The start time of the first non-working time cannot be earlier than the Calendar Day Start Time
  • The end time of the last non-working time cannot be later than the Calendar Day End Time

Sequence of Steps#

Select the desired Employee Calendar Days in the Calendar, then press Set Non-Working Time and follow the steps below:

  1. Verify the information.
  2. Optionally enter a description.
  3. Specify the non-working time type (note that the possible non-working day types are taken from the lookup table EmployeeCalendarNonWorkingTimeType)
  4. Enter the start and end time
  5. Optionally, enter a comment.
  6. Press the Set button to complete the transaction.
