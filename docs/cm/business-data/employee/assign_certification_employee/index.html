Assign Certification to Employee#

🔒 Certification.AssignEmployees

Overview#

This operation assigns Certifications to the selected Employee.

Preconditions#

  • The Employees are Active and do not have currently other manager assigned.

Sequence of Steps#

To assign one or more Certifications to a specific Employee, open the page of the Employee, navigate to the Certifications section of the page and press the Assign button.

Step 1: Details#

  1. Select the Certifications that should be assigned by using the button or remove them by using the button.
  2. A planned date can be defined if the Certification will be achieved at a point in the future and the state should be Assigned.
  3. If the Employee already has the Certification, the state can be set to Active by setting the Granted flag. This will set the Certification Date to the present date and time. You can also do this directly by using the Grant Certification to Employee operation.
  4. You can set the Employee as a Trainer or Trainee.
  5. The validity date is determined by the Certification validation date. However, if the Employee is set as Trainee the validation date is determined by: Certification Date + Training Maximum Duration.
  6. Optionally enter a remark for the assignment.
  7. Select the Assign button to complete the operation.
