Special Create Transfer Requirement for Material#

🔒 TransferRequirement.SpecialCreateForMaterial

Overview#

This operation is used to create a new Transfer Requirement for a specific Material using a selected BOM context.

Preconditions#

  • The Material exists and is Active.

Sequence of Steps#

Step 1#

  1. In the entity page of a Material that fulfils the criteria, navigate to the Transfer Requirements section and select the Create button in the section.
  2. Optionally select a Data Group for the Transfer Requirement.
  3. Select the appropriate Area for which the Transfer Requirement will be created.
  4. Select the Request Type to be fulfilled.

  5. The values for Source Location and Destination Location will be automatically filled:

    • Source Location will be set according to the Transfer Requirement Type of the For Location Area
    • If the For Location is a Storage Area, the Destination Location is set with that Storage Area; if the For Location is a Production Line, the Destination Location is set with the defined Destination Location of the Transfer Requirement Type if it is configured therein or with the For Location if it is not configured.
    • Information on Flow, Step and Flow Path will be automatically displayed since they are inherited from the Material.

  6. Specify the Priority of the Transfer Requirement.

  7. Define the delivery due date. The due date is the latest point in time when the Transfer Requirement must be completed. Pick a date from the calendar and a time by clicking on the clock icon.

  8. Select Next to define the Transfer Requirement Items.

Step 2 - BOM#

  1. On the left side panel, select the items from the Material BOM that will be included in the Transfer Requirement. Select Next to edit information for those items.

Note

If there is a BOM of scope Materials associated to a Material that has characteristics, the system will only display BOM Products that have the same characteristics defined for the selected Material.

Step 3 - Transfer Requirement Items#

  1. For each of the Products displayed in the left side panel, specify the Requested Quantity.

    Note

    The system will only consider BOM Items with positive Quantity.

  2. Optionally, if the Source Location Area is not external, a specific existing Material can be requested.

  3. Select the Create button to complete the creation of the Transfer Requirement.
