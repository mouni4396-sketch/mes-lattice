Create Transfer Requirement for Maintenance Activity Order#

🔒 TransferRequirement.Create

Overview#

This operation is used to create a new Transfer Requirement for a specific Maintenance Activity Order

Preconditions#

  • The Maintenance Activity Order exists and is Active.
  • The Maintenance Activity Order must be in one of the following Execution states: Requested, Approved, Released, or In Progress.

Sequence of Steps#

Step 1#

  1. In the entity page of a Maintenance Activity Order that fulfils the criteria, navigate to the Transfer Requirements section and press the Create button in the section.
  2. Optionally select a Data Group for the Transfer Requirement.
  3. Select the appropriate Area for which the Transfer Requirement will be created.
  4. Select the Request Type to be fulfilled. The available Request Types depend on the Area selected above and can be viewed and edited on the Area page. More information on the Manage Transfer Requirement Types page.

  5. The values for Source Location and Destination Location will be automatically filled:

    • Source Location will be set according to the Transfer Requirement Type of the For Location Area.
    • If the For Location is a Storage Area, the Destination Location is set with that Storage Area.
    • If the For Location is a Production Line, the Destination Location is set with the defined Destination Location of the Transfer Requirement Type if it is configured therein or with the For Location if it is not configured.

  6. Specify the Priority of the Transfer Requirement.

  7. Define the delivery due date. The due date is the latest point in time when the Transfer Requirement must be completed. Pick a date from the calendar and a time by clicking on the clock icon.

  8. Select Next to define the Transfer Requirement Items.

Step 2 - BOM#

  1. On the left side panel, select the items from the BOM that will be included in the Transfer Requirement. Select Next to edit information for those items.

Step 3 - Transfer Requirement Items#

  1. If a substitute Product is defined in the BOM, choose the Product from the list of possibilities, otherwise the Product can not be changed.
  2. For each of the Products displayed in the left side panel, specify the Requested Quantity.
  3. Optionally, if the Source Location Area is not external, a specific existing Maintenance Activity Order can be requested.
  4. Decide whether to allow substitutes for this Product. This option is only available if the Product is set in the BOM as allowing substitutes.
  5. Select the Create button to complete the creation of the Transfer Requirement.
