Release Transfer Requirement Items#

🔒 TransferRequirement.ReleaseItems

Overview#

This operation is used to release one or more items from a Transfer Requirement.

Setup#

No special setup is required other than to meet the preconditions.

Preconditions#

  • The Transfer Requirement must be Active.
  • The Transfer Requirement system state must be Approved.

Sequence of Steps#

Step 1#

  1. Review the information for each of the items.
  2. Selects which items to release considering that:

  3. If the Transfer Requirement Enable Partial Release is false, the whole Transfer Requirement must be released, however if Enable Partial Release is true, select the Released Quantity for each Transfer Requirement Item.

    Note

    User can only increase the value of the Released Quantity.

  4. User can enter the Quantity to Release for each Transfer Requirement for any item where the difference is larger than zero. To select the entire quantity, press the "Release all remaining" button.

  5. Press Release to complete the operation.
