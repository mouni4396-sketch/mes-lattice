Create Transfer Requirement#

🔒 TransferRequirement.Create

🔒 TransferRequirement.CreateTemplate

🔒 TransferRequirement.CreateFromTemplate

Overview#

This operation is used to create a new Transfer Requirement. A template can also be created using a similar procedure and there is also the possibility of using a template to create the new object as well. This selection can be done in the main entity menu.

Sequence of Steps#

Step 1#

  1. Specify a Name for the Transfer Requirement.
  2. Optionally select a Data Group for the Transfer Requirement.
  3. Select the appropriate Area for which the Transfer Requirement will be created.
  4. Select the Request Type to be fulfilled. The available Request Types depend on the Area selected above and can be viewed and edited on the Area page. More information on the Manage Transfer Requirement Types page.
  5. The values for Source Location and Destination Location will be automatically filled:
    • Source Location will be set according to the Transfer Requirement Type of the For Location Area.
    • If the For Location is a Storage Area, the Destination Location is set with that Storage Area.
    • If the For Location is a Production Line, the Destination Location is set with the defined Destination Location of the Transfer Requirement Type if it is configured therein or with the For Location if it is not configured.
  6. Specify the Priority of the Transfer Requirement. By default, the priority of the task is set to Medium, but it is possible to set it also with the value Low or High.
  7. Define the delivery due date. The due date is the latest point in time when the Transfer Requirement must be completed. Pick a date from the calendar and a time by clicking on the clock icon.

  8. Optionally, specify additional context data for the Transfer Requirement:

    • For Resource
    • For Resource Location
    • For Material
    • For Step
    • For MAO
    • For Production Order
    • For Maintenance Activity Order

  9. Select Next to define the Transfer Requirement Items.

Step 2 - Transfer Requirement Items#

  1. On the left side panel, add as many items as desired (press in the top right of the grid to add, and to remove), specifying for each item:

    • Product.
    • Bin Code (when the selected Product requires one).
    • Requested quantity (Must be larger than zero. The value for the Required Quantity will be displayed automatically depending on the already consumed quantity).

    Info

    The Required Quantity field accepts up to eight decimal places, but always displays 3 decimal places rounded up.

    • Units.

  2. Optionally, if the Source Location Area is not external, a specific existing Material can be requested.

  3. Select the Create button to complete the creation of the Transfer Requirement.
