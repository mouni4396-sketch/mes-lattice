Change Set Page#

🔒 ChangeSet.Show

Details#

  • Details - displays general information on the Change Set. Additionally, it displays the Details of the Change Set, as illustrated below.

  • Items - displays the Change Set Items in a list in which it will be possible to visualize the name of the Change Set Item, its type, the approval role or the name of the approver in charge of approving the item. In case the Change Set Item has already been approved, it will also be possible to see its approval date and time.

If a Change Set Item still has not been approved, it is possible to tick its checkbox and click the Approve Item button to approve it. To find out more about approving Change Set Items, see Approve Change Set Items.

If the Change Set is still in the "Created" state, it is possible to click Edit to modify these Change Set Items concerning the "Approval Role".

  • State Reviewers - displays the Change Set Reviewers associated to this Change Set. The Reviewer must explicitly approve the Change Set at a certain state. Within this view there are three separate tabs with information on the current state review process:

    • Approvals - all Approvals for the Change Set
    • Reviewers - all Reviewers for the Change Set
    • History - all the history of approvals for the Change Set

  • Subscribers - displays all the subscribers of the current Change Set.

References View#

This view combines information concerning other objects that have references to the current object:

  • Where Used - displays the set of relationships between the Change Set and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current BOM object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
