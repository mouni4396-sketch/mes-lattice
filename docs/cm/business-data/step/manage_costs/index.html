Manage Costs#

🔒 Step.Edit

Overview#

This operation is used to define the Step costs.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Costing module is properly licensed in the system.

Sequence of Steps#

Step 1: Manage Costs#

If the Costing module is properly licensed in the system, the Costs tab will be enabled on the right-hand sidebar and you will be able to define the Step costing information.

  1. Optionally, modify the Step costs from the following available options:

    • Step Standard Costs
      • Step Standard Fixed Cost - fixed costs of using the Step.
      • Step Standard Cost Per Unit - costs per processed unit in this Step. It should not include resource (machine) costs.
      • Step Standard Cost Per Hour - costs of this Step per hour.
    • Resource Standard Costs (Forecast)
      • Resource Standard Fixed Cost - fixed costs of using this Resource.
      • Resource Standard Cost Per Unit - costs per processed unit using this Resource. In principle, exclusive with Resource Cost per Hour but can be complementary.
      • Resource Standard Cost Per Hour - costs per hour of using this Resource. In principle, exclusive with Resource Cost per Unit but can be complementary.
    • Labor Standard Costs (Forecast)
      • Labor Standard Costs Per Hour - costs per hour of using a Resource in this Step by a member of the labor force.

  2. Select Update to complete the operation.
