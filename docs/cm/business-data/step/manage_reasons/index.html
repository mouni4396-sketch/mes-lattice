Manage Reasons#

🔒 Step.Edit

Overview#

This operation is used to define and manage the Step's Scheduling details.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Step is created and it is Active.

Sequence of Steps#

Step 1: Reasons#

  1. Go to the Reasons tab on the sidebar and specify the Reasons for the Step.
  2. Loss Reasons can be qualified to apply to any of these transactions: Record Loss, Terminate and Assemble; set to true or false, according to your preferences. In addition, for reporting purposes, it is possible to specify a different Step in which the loss will be accounted to.
  3. It is possible to define up to four Loss Classifications. When defined, the user will be forced to provide the additional classification information. Each classification requires a name and the user can optionally, select a lookup table from the available options, from which the values for the classification will be taken.
  4. Specify the bonus Reasons for the Step.
  5. Specify the Off-Flow reasons for the Step. Each Off-Flow reason must be classified as being applicable to Rework, Temporary Off-Flow or both and it must apply to at least one of them.
  6. Specify the Hold reasons for the Step.
  7. Specify the Defect reasons for the Step.
  8. Select Update to complete the operation.
