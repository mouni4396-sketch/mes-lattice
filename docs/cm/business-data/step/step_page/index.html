Step Page#

🔒 Step.Show

The Step page displays all the operations that can be performed within a specific Step. Additionally, it displays the details of the Step in different view modes, as described below.

Details View#

The Details view displays all the following information:

  • Details - displays general information on the Step.
  • Logical Names - displays the logical names to allow easy identification and reusability for the Step.
  • Areas - enables the addition and removal of Areas to/from the Step and the possibility to visualize the existing ones.
  • Reasons - enables the creation and elimination of Loss, Bonus and Off-Flow Reasons and to visualize the existing ones.
  • Future Actions - enables you to manage and see the Future Actions that are associated to the Step.
  • Costing - enables the visualization of Step Standard Costs and Resource Standard Costs previously entered by you (only if the Costing module is properly licensed in the system).
  • Sampling - displays information on the existing Sampling Plans and allows you to manage them (only if the Sampling module is properly licensed in the system).
  • Scheduling - displays information on the Scheduling and Planning of the Step and allows you to manage them (only if the Scheduling module is properly licensed in the system).
  • Inspections - displays information on the existing Inspection Plans active for the Step, as well as the configurations and active instances.
  • Attachments - shows the documents that are attached to the Step.

Schedule View#

The Schedule View is available when the Include in Scheduling property is set to true. This view provides a timeline view of the Materials set to be processed at this Step. You can filter by Area, Resource or job state.

  • Materials - displays a comprehensive list of the scheduled Materials at this Step, grouped by the scheduled Resource, including all relevant information for each one.

  • Calendar view - displays a Gantt Chart that shows all the different Materials scheduled at this Step and assigned to a specific Resource.

    Info

    This view is very similar to the Schedule View available in the Schedule page. For more information, see Schedule Page.

  • Unplanned Materials - displays a list of Materials currently on the Step but outside the defined Schedule.

Contexts View#

This view shows information concerning all the contexts currently connecting the Step to other objects in the system:

  • BOM Context - displays the existing Relations between the Step and any BOM existing in the system.
  • Certifications Context - displays the existing Relations between the Step and any Certifications existing in the system.
  • Chart Context - displays the existing Relations between the Step and any Chart existing in the system.
  • Checklist Context - displays the existing Relations between the Step and any Checklist definition existing in the system.
  • Data Collection Context - displays the existing Relations between the Step and any Data Collections existing in the system.
  • Document Context - displays the existing Relations between the Step and any Documents configured in the system.
  • Durables Context - displays the existing Relations between the Step and any Durables configured in the system.
  • In-Process Verification - displays the existing Relations between the Step and any In-Process Verification configured in the system.
  • Inspection Plan Context - displays the existing Relations between the Step and any Inspection Plans configured in the system.
  • Line Flow Context - displays the existing Relations between the Step and any Line Flows configured in the system.
  • Material Container Type Context - displays the existing Relations between the Step and any Material Containers configured in the system.
  • Rework Limits Context - displays the existing Relations between the Step and any Rework Limits configured in the system.
  • Sampling Pattern Context - displays the existing Relations between the Step and any Sampling Pattern configured in the system.
  • Service Context - displays the existing Relations between the Step and any Service configured in the system.
  • Split Track-Out Context - displays the existing Relations between the Step and any Split and TrackOut configured in the system.
  • Time Constraints Context - displays the existing Relations between the Step and any Time Constraints configured in the system.
  • Yield and Cycle Time - displays the existing Relations between the Step and any Yield and Cycle Time configured in the system.

Note

To be able to edit the data contained in the Context tables, you will need the ContextResolution.EditData security feature.

Compare View#

🔒 Step.Compare

This view provides a quick visual comparison between the selected entity version and any other version that can be selected through it. You can also export the comparison results to a PDF file through the Export Comparison button on the top ribbon. For more information, see Compare Entity Versions.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the Step and other entities and enables you to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the Step and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current Step object:

  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
