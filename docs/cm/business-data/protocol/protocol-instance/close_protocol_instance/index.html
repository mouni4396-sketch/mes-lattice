Close Protocol Instance#

🔒 ProtocolInstance.Close

Overview#

This operation is used to close a Protocol Instance.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Protocol Instance exists, is active and is in system state Open.
  • The Main State of the current Protocol Instance is the final state of the State Model.
  • All the mandatory fields of the Current Protocol Instance Path have been filled.
  • The Checklist associated with the Current Protocol Instance Path is in system state Closed.
  • All tasks associated with the Protocol Instance are either completed or canceled.
  • All Protocol Instance Materials that are Active and whose Disposition is defined as Use As Is or Is Disposition Executed, must be true.

Sequence of Steps#

  1. Select the Protocol Instance.
  2. Optionally, enter a comment.
  3. Select Close to complete the operation.
