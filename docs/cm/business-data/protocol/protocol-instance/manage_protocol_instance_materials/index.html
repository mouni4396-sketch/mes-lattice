Manage Protocol Instance Materials#

🔒 ProtocolInstance.ManageMaterials

Overview#

This operation is used to associate or dissociate Materials from the Protocol Instance.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Pre-Conditions#

  • The Protocol Instance exists, is Active, and its System State is Open.
  • The Materials being added or removed exist and are Active in the system.

Sequence of Steps#

Step 1#

  1. Select the Manage button on the top ribbon followed by Materials:

  2. In the Manage Protocol Materials wizard, use to add new Materials to associate with the Protocol Instance:

  3. The context will be updated automatically:

  4. Optionally, add a comment.

  5. Select Update and the updated information can be accessed by selecting the Materials section on the right:

Note

Available dispositions can be managed when the Protocol is created.
