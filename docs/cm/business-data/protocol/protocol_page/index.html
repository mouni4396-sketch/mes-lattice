Protocol Page#

🔒 Protocol.Show

The Protocol page displays all the operations that can be performed within a specific Protocol. Additionally, it displays the details of the Protocol in different view modes, as described below.

Details View#

The Details view displays all the following information:

  • Details - displays general information on the Protocol.
  • Parameters - shows the entire list of parameters within the Protocol scope (parameters library).
  • Active instances - enables the visualization and the possibility to open the instance from the Protocol.
  • Attachments - shows the documents that are attached to the Protocol.
  • History - displays the history of the operations, associated information, user(s), date and time.

Flowchart View#

The Flowchart view presents the flowchart of the Protocol's state and its flow of states.

The information that is displayed in the flowchart is subject to being modified on the right-hand side column, in the View tab. Setting the buttons Description, Role, Checklist and Parameters to true will add each of these details to the flowchart state, while setting them to false will remove them from the flowchart state.

In this view, it is also possible to edit the Protocol state, in case the Protocol is in system state Created. To do so, select the three-dot menu of the Protocol state and select Settings. For more information, see Create Protocol.

In case the Protocol state is Active or Effective, it will not be possible to edit the system state. A New Version of the Protocol will have to be created for the modifications to be carried out.

Compare View#

🔒 {{entityname}}.Compare

This view provides a quick visual comparison between the selected entity version and any other version that can be selected through it. You can also export the comparison results to a PDF file through the Export Comparison button on the top ribbon. For more information, see Compare Entity Versions.

References View#

This view combines information concerning other objects that have references to the current object:

  • Relations - displays the existing Relations between the {{ entityname }} and other entities and enables the user to edit them. For more information on Relations, visit the section Relations.
  • Where Used - displays the set of relationships between the {{ entityname }} and the other objects used throughout the system.

History View#

This view combines information concerning other objects that have references to the current {{ entityname }} object:

  • Change Set History - displays the history of the change sets associated to the object. For more information on Change Set history, visit the Change Set History page.
  • History - displays the history of the operations, associated information, user(s) performing the changes and date and time of the changes.
