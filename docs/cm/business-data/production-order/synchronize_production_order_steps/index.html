Synchronize Production Order Steps#

Overview#

This operation to generate the Production Order Steps and Dependencies to be scheduled for Products with ScheduleMode set to Production Order. This operation can be executed automatically during Release/Start/Create operations to suggest the necessary Production Order Steps that need to be created to fulfill the Production Order, or manually to refresh the existing Production Order Steps.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Production Order must exist, must be Active and in state Created, Released, InProgress, Completed.
  • The Production Order must have a FlowPath assigned, either manually or through the defined Product.
  • If a Facility is specified for the Production Order, it must match the resolved Flow Path.
  • The Step in the Flow Path must have the Production Order Scheduling Mode property defined and set to Material and the Production Order Step Size defined.
  • The Product of the Production Order must have the Include In Schedule property set as true and the Scheduling Mode set to Production Order.

Sequence of Steps#

Navigating to the Production Order Steps section on the right hand side of the screen will scroll the page to the appropriate section and the Synchronize Production Order Steps wizard can be opened by pressing the Synchronize button.

  1. Review the Production Order details by expanding the Production Order section.
  2. Select Synchronize to start the operation.

Info

All Production Steps will be removed and new ones will be created to reflect the current status of the scheduling and manufacturing process.
