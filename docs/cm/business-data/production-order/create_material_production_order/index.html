Create Material For Production Order#

🔒 Material.Create

Overview#

This operation is used to create a Material associated with a Production Order.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Order Management module must be properly licensed in the system.
  • The Production Order must be in the state Created, Released, In Progress or Completed.
  • The Production Order must not be restricted.
  • If the Production Order has an owner role defined, you must belong to that role.

Sequence of Steps#

The sequence of steps is similar to the one described in the transaction Create Material with the following exceptions:

  • The Production Order property is set with the current Production Order and it cannot be changed.
  • The Facility is set with the Production Order Facility (if any), but it can be changed.
  • The Product is set with the Production Order Product and it can only be changed to other Products in the reverse Production Order Product sub-products tree.
  • The priority is set with the Production Order priority - but it can be changed.
  • The due date is set with the Production Order planned end date - but it can be changed.
  • The quantity is set with (Production Order Quantity - Production Order In Progress Quantity - Production Order Completed Quantity) / (Product Standard Yield) adjusted to the Material Step units, but it can be changed.
  • The Flow is set with the Production Order Flow and Production Order Flow Path (if defined) - but it can be changed.
  • The Production Order Characteristics will be matched against the current Material Product Characteristics – the matching Characteristics cannot be changed.
