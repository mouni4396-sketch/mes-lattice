Change Production Order Characteristics#

🔒 ProductionOrder.ChangeCharacteristics

🔒 ProductionOrder.SpecialChangeCharacteristics

Overview#

This operation is used to change the Production Order Characteristics.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Production Order exists and it is Active.
  • To Change Production Order Characteristics, the System State of the Production Order must be Created.
  • To Special Change Production Order Characteristics, the System State of the Production Order is not Closed.
  • The Production Order has Characteristics or the associated Product has Characteristics.

Sequence of Steps#

The Change Production Order Characteristics wizard can be called from the Production Order page within the Business Data Group by selecting the Characteristics section.

  1. In the Characteristics section, where the current Production Order Characteristics are displayed, select Change.

  2. Optionally, review and adjust the Production Order Characteristics using the following actions:

    • Synchronize - validates the existing Production Order Characteristics against those of the currently associated Product, highlighting entries as valid or invalid.
    • Add Missing - adds to the Production Order any Product Characteristics that are not yet present, making them available for value entry.
    • Remove - removes a selected Characteristic from the Production Order. To discard all Characteristics at once, use Remove All.

  3. Optionally, modify the Value of existing Production Order Characteristics that match the Product Characteristic.

  4. Optionally, set a value for the Product Characteristic that did not exist for the Production Order. The value can be entered manually as free text or as a predefined value from the specified Source Lookup Table.

  5. Confirm that all the mandatory fields are filled.

  6. Select Change to complete the operation.

    Info

    If there are active Materials currently assigned to the Production Order, changes may affect the processing of Materials associated with the Production Order.
