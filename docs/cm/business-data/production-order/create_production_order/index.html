Create Production Order#

🔒 ProductionOrder.Create

🔒 ProductionOrder.CreateTemplate

🔒 ProductionOrder.CreateFromTemplate

Overview#

The operation is used to create a Production Order. A template can also be created using a similar procedure and there is also the possibility of using a template to create the new object as well. This selection can be done in the main entity menu.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Order Management module must be properly licensed in the system.
  • The Production Order does not already exist in the system.
  • If a Facility is defined, the Default Flow Path Step must exist in the defined Facility.

Sequence of Steps#

The Manage Characteristics wizard can be called from the Product page by selecting Characteristics from the section menus on the right.

Step 1: General#

  1. Enter the Name of the Production Order. The name can be left blank if there is a name generator configured to provide unique Material names.
  2. Optionally, enter a Description.
  3. Select the Production Order Type. The list of possible values is taken from the ProductionOrderType Lookup Table.
  4. Select the Production Order State Model and the Production Order State Model State.
  5. Select the System State of the Production Order: Created or Released. If the Production Order System State is set to Released it is necessary to specify a Planned Start Date and a Planned End Date.
  6. Optionally, specify the Order Number this Production Order refers to.
  7. Optionally, define the Order Line number for this Production Order.
  8. Optionally, define an Owner Role for the Production Order. If the Owner Role needs to be changed at a later stage, this change can be made by any user (not only by the user(s) that belong(s) to the existing owner role).
  9. Optionally select a Customer for the Production Order.

  10. Optionally, define a Facility to be associated with the Production Order. This is generally used for filtering.

  11. Specify the Product the Production Order refers to.

    Note

    If the Product of the Production Order has Characteristics with Configurable set to true, the mandatory Production Order Characteristics must be entered (see Step 2: Characteristics below).

  12. Optionally, define a Flow Path (formed by a Flow and a Step) for the Production Order.

  13. Specify the Quantity of this Production Order.
  14. Specify the Units of the Production Order quantity.
  15. Specify the value for the Under Delivery Tolerance, in percentage. A value of 10% means that a delivery 10% below the Production Order defined quantity is acceptable. The final minimum acceptable value is automatically calculated and displayed after this field.

  16. Specify the value for the Over Delivery Tolerance, in percentage. A value of 10% means that a delivery 10% above the Production Order defined quantity is acceptable. The final maximum acceptable value is automatically calculated and displayed after this field.

    Note

    The Product Yield (in percentage) is shown on the screen.

  17. Define a Due Date for the Production Order.

  18. Define the Priority for the Production Order.

  19. Optionally, define a Planned Start Date and a Planned End Date - if the Production Order is set as Released, the Planned Start Date and Planned End Date need to be entered (see 5 above).

  20. Specify whether the Production Order must be included in Schedules of type Planning, in which case specify whether the BOM explosion must take place for the Production Order. This option is also taken into consideration when performing the Start Production Order operation.
  21. Specify whether the system must enforce that all the Materials that are associated with the Production Order belong to the reverse Product Sub-Products tree of the Production Order Product by checking or unchecking the option Validate Material Products.
  22. Specify whether the Production Order must automatically be restricted when completed, by checking or unchecking the Restrict Order on Completion option. A restricted Production Order cannot have Materials assigned or removed from it with the exception of Split and Expand Material.
  23. Optionally, type a Note in the Additional Information section to capture any remarks related to the Production Order.
  24. Specifies whether the Product Characteristic Rules are to be applied for this Production Order by checking or unchecking the respective option.

  25. Specify whether changes in the state of the Production Order must be sent to a Distribution List. In this case it is necessary to specify a list.

    Note

    If notifications have been configured, it is mandatory to specify a Distribution List.

    Info

    If a Distribution List is defined, it must be well formed - it must contain valid email addresses, and if multiple email addresses are provided, they must be separated by a semicolon.

  26. Optionally, define a date when the system should trigger a notification to the defined Distribution List to report on the state of the Production Order.

    Note

    It is possible to release the Production Order at the moment of its creation. To do so, select Released for the System State instead of Created (which is the default System State). Additionally, for a Production Order to be released, it needs to have planned start and end dates.

  27. Select Create to complete the operation or Next to define Characteristics.

Step 2: Characteristics#

Only available if the Product associated to the Production Order has configurable Characteristics set to true, or if either the Product or the Production Order has Characteristics.

  1. For this operation, you must provide a value for each characteristic, either by entering manually as free text or by selecting a predefined value from the specified Source Lookup Table.

  2. Select Create to complete the operation.

    Info

    It is possible to define a default value for the Use Product Characteristic Rules by adding the entry Context=ProductionOrder.Create, Element=UseProductCharacteristicRules in the Generic Table GUIElementDefaultValue.
