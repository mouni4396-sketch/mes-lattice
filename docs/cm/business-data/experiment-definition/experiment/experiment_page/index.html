Experiment Page#

🔒 Experiment.Show

The Experiment page displays all the operations that can be performed within a specific Experiment. Additionally, it enables you to check the details of the Experiment in different view modes, as described below.

Details#

In this tab, it is possible to see the Experiment's general data such as the concerning Experiment Definition, and all the settings that have been configured at the creation level. If the Experiment is already terminated, you can also see its results and conclusions (if they have already been edited).

Sub-Materials#

The Sub-Materials' section will present the list of sub-materials, containers and main material groups used in the Experiment:

It is possible to visualize additional information on the Experiment by changing the view mode. Change views by clicking on the icon on the top right-hand side of the screen and choosing the option Matrix.

Matrix#

The Matrix view will allow you to see all the material groups, sub-materials and sub-materials' numbers, steps, and actions in a grid layout.

The pane on the right-hand side of the screen will enable you to see further information on each of these tabs - Experiment, Step, Material Group, Action, Sub-Material.

By clicking on each sub-material number, it is possible to see its specific details such as main material, product, quantity, container and associated facility, flow and step. Hovering over the specific sub-material will also display contextual information on it.

It is also possible to filter out Steps, Material Groups and Actions. Each option will default to "All" and will display all the Steps, Material Groups and Actions related to the specific Experiment.
However, all the items are subject to being filtered, thus displaying only the information that you wish to see.
