Special Create Experiment#

🔒 Experiment.SpecialCreate

Overview#

This operation is similar to Create Experiment but it has less restrictions.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

Same as the preconditions for Create Experiment but without the following restriction:

  • If the Experiment Definition defines a Product or a Product Group, the Material must have that Product or Product Group.
  • The Material must have the same Flow as the Experiment Definition.
  • Taking the full flow structure into account, the Material did not reach the First Flow Path as defined in the Experiment Definition (can be in any System State) or is at the First Flow Path as defined in the Experiment Definition (the State must be Queued).

Sequence of Steps#

  1. Start by choosing the Material that will be the subject of the Experiment.

  2. Optionally, use the available filters (Flow, Step, Product Group, and Product) to filter the Material.

  3. After choosing the Material, the system will display the most relevant information. Select Next to assign the Sub-Materials to the Experiment.

    Info

    If the chosen Material does not belong to the Experiment Flow, the system will show the warning displayed in the image above. However, this will not prevent you from proceeding with the operation.

  4. Assign the Sub-Materials, as shown in Create Experiment.

  5. Optionally, enter a Comment.

  6. Once the Sub-Materials have been assigned, select Create to complete the operation.
