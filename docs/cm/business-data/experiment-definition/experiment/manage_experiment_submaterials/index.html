Manage Experiment Sub-Materials#

🔒 Experiment.Edit

Overview#

This operation is used to manage the Sub-Materials associated to an Experiment.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Experiment exists and is Active.

Sequence of Steps#

Step 1: Manage Sub-Materials#

  1. Select the number and Material Group you want to change the Sub-Material assignment and select a new Sub-Material. For quicker assignment, select the icon on top of the material group panel to define the criteria by which you will assign the Sub-Material. Select one of the options:

    • Assign by Sub-material Name - The first Experiment number is assigned with the first Sub-Material sorted by name (ascending).
    • Assign by Container and Position - The first Experiment number is assigned with the first Sub-Material sorted by Container and Position (ascending).
    • Assign Remaining Randomly - positions are assigned randomly.
    • Clear - remove current assignments.

  2. Select Update to complete the transaction.
