Task#

🔒 Task.Show

A Task is a generic action item that can be assigned to an Employee and that is tracked in the system.

The Task entity is part of the notifications module.

Task Lifecycle#

A Task, during its life cycle, follows the state model as illustrated in the next picture.

graph TD
    Start ==> A1[Created]
    A1 ==> A2[Released]
    A2 ==> A3[In Progress]
    A3 ==> A4[Completed]
    A1 --> A5[Canceled]
    A2 ----> A1
    A3 ----> A1
    A2 --> A5
    A3 --> A5
