Manage Product Group Parameters#

🔒 Product.Edit

Overview#

This operation is used to define the parameters for the Product Group.

Setup#

No specific setup is required other than to meet the precondition of the transaction.

Preconditions#

  • The Product exists and it is Active.

Sequence of Steps#

The Manage Product Group Parameters wizard can be called from the Product Group page within the Business Data Group, scrolling to the Parameters section and selecting Manage. In the wizard:

Step 1: Manage Planning#

  1. On the left side panel, add as many Source Parameters as desired (press in the top right of the grid to add, and to remove), specifying for each Source Parameter, depending on the type of Product Group:

    • The source Parameter.
    • The type: can be Specification or Characteristic. A Specification can be used for SPC integration and it can define a lower specification value, a target value and a upper specification value. A Characteristic is a constant value that is associated with the Product.

Info

A Parameter which is defined as Specification will set the Specification limits automatically on any Chart that has the Product as Context Key and that has the Spec Limits mode defined as Product.
