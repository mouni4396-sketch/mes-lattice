Create Setup Matrix#

🔒 SetupMatrix.Create

🔒 SetupMatrix.CreateTemplate

🔒 SetupMatrix.CreateFromTemplate

Overview#

This operation is used to create a Setup Matrix. A template can also be created using a similar procedure and there is also the possibility of using a template to create the new object as well. This selection can be done in the main entity menu.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Setup Matrix does not currently exist in the system.

Sequence of Steps#

Step 1: General Data#

  1. Provide a name for the Setup Matrix.
  2. Optionally, provide a description of the Setup Matrix.
  3. Select the Setup Matrix time scale (Seconds, Minutes, Hours, Days).
  4. Check the option Use Zero In Diagonal to use zero when transitioning from a Service to itself.
  5. Select Next to continue to the Services configuration of the Setup Matrix.

Step 2: Services#

To add Services manually, select them from the panel on the left-hand side and they will be added to the list of the Selected Services on the right-hand side. You can filter the list to make it easier to add the Services.

Select Next to continue to the Setup Matrix configuration of the Setup Matrix.

Step 3: Setup Matrix#

Each Service selected in the previous panel is added to the list on the left hand side of the panel (From Services) and each of them have a relation to the services listed in the center part of the dialog (To Services). Select the From and the To services and enter the desired value in the specified time scale.

You can preview the matrix by pressing the Preview in the top right-hand corner of the dialog.

Info

In case that the option Use zero in matrix diagonal has been selected, the diagonal is pre-filled with zeroes and its value cannot be changed so it won't be listed in the dialog.

Select Create to complete the operation and the new Setup Matrix will be created.
