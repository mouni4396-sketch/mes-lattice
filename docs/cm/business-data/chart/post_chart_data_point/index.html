Post Data Point to Chart#

🔒 Chart.PostDataPoint

Overview#

This operation is used to post a new data point to a Chart by providing the individual reading values.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Chart is Active and it is enabled.

Sequence of Steps#

Step 1: Context#

  1. Select Post Data Point on the top ribbon, followed by Post Chart Data Point.
  2. Fill out the Context. It is possible to or supplementary contexts.
  3. Enter the Context Details - Material and Product in this example.
  4. Optionally, enter a comment.
  5. Select Next.

Step 2: Readings#

  1. Enter the value for the readings. The value must comply with the minimum and maximum sample size definition for the Chart.
  2. It is possible to set individual names for the readings by selecting Edit next to each of the readings.
  3. Optionally, enter a comment.
  4. Select Post to complete the transaction.

Info

If a comment is entered when posting the data, the comment will be automatically associated with the data point.

When posting data to the Logical Chart for the first time, it will be automatically created with the default settings from the Chart.

Depending on the configured Statistical Point Chart (SPC) rules for the Chart, a Protocol may be opened or a DEE Action may be automatically executed when a violation occurs.

When a data point is posted, key metrics are calculated and stored. These values are later used during the data loading and transformation stages of the data warehouse, as well as during cube processing in Analysis Services (AS).
