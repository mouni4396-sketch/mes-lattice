Post Aggregated Data Points#

🔒 Chart.PostDataPoint

Overview#

This operation is used to post a new data point to a Chart, but instead of providing individual readings data, only the aggregated data is posted.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Chart is Active and enabled.
  • The Chart is of a Variable Chart type.

Sequence of Steps#

Step 1: Context#

  1. Select Post Data Point on the top ribbon, followed by Post Chart Data Point Aggregated.
  2. Fill out the Context. It is possible to or supplementary contexts.
  3. Enter the Context Details - Material and Product for this example.
  4. Optionally, enter a comment.
  5. Select Next.

Step 2: Readings#

  1. In the grid, specify the sample size (must be compatible with the sample size sample definition), and the aggregated data for Indicator 1 and Indicator 2.
  2. Optionally, enter a comment.
  3. Select Post to complete the transaction.

Info

When posting data to the Logical Chart for the first time, the Logical Chart is automatically created with the default settings from the Chart.

Info

Depending on the configured SPC rules for the Chart, a Protocol may be opened or a DEE Action may be automatically executed when a violation occurs.
