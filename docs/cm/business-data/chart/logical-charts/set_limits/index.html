Set Limits#

🔒 Chart.SetLimits

Overview#

This operation is used to update the Limits of a Chart. It can also be used to change the control limits from manual to automatic.

Setup#

No special setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Chart is Active.
  • The Specification Limits can only be defined if the mode is manual.

Sequence of Steps#

Step 1: Limits#

  1. Select whether the centerlines are calculated automatically or not. If they are to be calculated automatically, you must also specify the window size.
  2. Define whether to use Learning Mode (the Chart begins without control limits and the limits are set and used automatically when the centerlines are recalculated).
  3. Select whether to disable the automatic calculation after learning if the Learning Mode is active.
  4. If the Specification Limits mode is Chart, you can modify the Upper, Target, and Lower specification limits.
  5. Specify whether the Control Limits are automatic or not. If they are not automatic, you can set the centerlines and control limits manually, and leave some of them empty.
  6. Specify the value for Centerline 1 (the meaning depends on the Chart Type) and for variable Charts; do the same for Centerline 2 (the meaning depends on the Chart Type).
  7. Specify the value for the default Standard Deviation.
  8. Select Next to continue.

Step 2: Logical Charts#

  1. Specify whether the Chart Limits should be calculated automatically or not.
  2. Define whether to use Learning Mode (this clears all Centerline options).
  3. Select whether to disable the automatic calculation after learning if the Learning Mode is active.
  4. Specify the Specification Limits of the Logical Chart.
  5. Specify whether the Control Limits are of type Automatic (using the standard statistical formulas) or not. If the Control Limits are not Automatic, you can optionally set the Upper and Lower Control Limits as well as the centerlines.
  6. If the Control Limits are Automatic, specify the value for Centerline 1 (the meaning depends on the Chart Type) and for variable Charts; do the same for Centerline 2 (the meaning depends on the Chart Type).
  7. Specify the value for the default Standard Deviation.

  8. At any time, you can copy the limits of the main Chart to all or to a selected number of Logical Charts by selecting the desired Logical Chart(s) and selecting the Copy dropdown.

  9. Optionally, enter a comment.

  10. Select Update to complete the operation.
