Add Logical Chart#

🔒 Chart.Edit

Overview#

This operation is used to create a Logical Chart.

Setup#

No specific setup is required other than to meet the preconditions of the transaction.

Preconditions#

  • The Chart does not currently have a Logical Chart with the same contexts.

Sequence of Steps#

Navigate to the Logical Chart section of the main Chart page and select Add to access the Add Logical Chart wizard.

Step 1: Contexts#

  1. Select the context(s) to be used for the new Logical Chart.
  2. Optionally, enter a comment.
  3. Select Next to continue.

Step 2: General Data#

  1. Enter a description for your Logical Chart.
  2. Optionally, enter a comment.
  3. Select Next to continue.

Step 3: Centerlines#

  1. Choose whether the system should Auto Calculate Control Limits.
  2. Select whether the system should activate the Learning Mode for the current Logical Chart.
  3. Choose if the system will Disable Auto Calculation After Learning.
  4. Optionally, enter a comment.
  5. Select Next to continue.

Step 4: Limits#

  1. Specify the Upper, Target, and Lower specification limits.
  2. Select whether the system should Use Automatic Control Limits.
  3. Specify the value for Centerline 1 (the meaning depends on the Chart Type) and Centerline 2 (the meaning depends on the Chart Type) if available.
  4. Specify the Standard Deviation.
  5. Optionally, enter a comment.
  6. Select Next to continue.

Step 5: Display#

  1. Specify the Number to Histogram Interval.
  2. Define whether the Y-Axis Scale Mode (only for the first indicator) is automatic or manual. In case the Y-Axis Scale is manual, you need to specify the Minimum and Maximum values, as well as the Major Units of the scale.
  3. Optionally, enter a comment.
  4. Select Add to complete the operation and the new Logical Chart will be created.
